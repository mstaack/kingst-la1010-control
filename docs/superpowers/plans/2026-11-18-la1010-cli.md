# la1010 CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust CLI `la1010` that drives a Kingst LA1010 over USB and captures, measures, exports, and decodes UART, I²C, SPI and USB low/full-speed traffic. Output is plain text or NDJSON and is safe for agents to run.

**Architecture:**
- A library crate holds pure, unit-tested modules: units, stream, window, output, measure, decode, export, firmware, device protocol.
- Two thin hardware modules (`usb`, `capture`) wrap the device using `nusb`.
- The binary is a thin wrapper around the library.
- All signal processing works on a sorted stream of `Edge { sample, ch, level }`, so the same code path handles live capture, files and tests.

## Global Constraints

**Licensing and repo**
- License MIT. Vendor firmware is never committed, embedded or redistributed. `.gitignore` excludes `*.fw` and `*.bitstream`.
- The protocol layer is written from the spec's "Device protocol" section. Do not copy code from sigrok (GPL).

**Device**
- USB `77a1:01a2`. FX2 firmware file `kingst-la-01a2.fw`. Bitstream file `kingst-la1010{a0,a1,a2}-fpga.bitstream`. EEPROM magic `0x04`→a0, `0x07`→a1, `0x0a`→a2.
- Allowed rates: 800 MHz / n for n in 8..=65535, so the maximum is 100 MHz and the minimum about 12.2 kHz. Other values snap to the nearest n, with a stderr note.
- Threshold default 1.4 V, range ±4.0 V.

**CLI behaviour**
- Exit codes: 0 ok, 1 usage, 2 device/firmware/IO, 3 no result.
- Diagnostics go only to stderr. With `--json`, a stderr error is exactly one line `{"error":"…","code":N}`.
- Bounded by default:
  - `capture` and `measure` default to `-d 1s`.
  - `monitor` defaults to `--timeout 10s`; `--timeout 0` means unbounded.
  - `capture --trigger` waits at most `--timeout` (default 10s) for the trigger.
- NDJSON key order: `t`, `sample`, `proto`, `kind`, then decoder fields, then `text`.
- Every exit path halts the device: normal end, error, Ctrl-C, broken pipe.
- The firmware lookup order is `--firmware-dir`, `LA1010_FIRMWARE_DIR`, `$XDG_DATA_HOME/la1010`, `$HOME/.local/share/la1010`.

**Firmware fetch**
- URL `https://www.qdkingst.com/download/vis_linux`.
- Known-good table from v3.6.6 (size, CRC32):

| File | Size | CRC32 |
|---|---|---|
| `kingst-la-01a2.fw` | 5430 | `720551a9` |
| `kingst-la1010a0-fpga.bitstream` | 124412 | `a655cdd2` |
| `kingst-la1010a1-fpga.bitstream` | 125301 | `2333d203` |
| `kingst-la1010a2-fpga.bitstream` | 342524 | `d2cf8e9e` |

**Hardware safety**
- Every hardware step needs the user's explicit OK when executed.
- RTC1002 pattern generator (P0→CH0 is the only wiring): after use, restore `PGEN:PATT:STAT OFF`, `PGEN:FUNC ARB`, `PGEN:PATT:STIM 8.68E-6`.
- Never enable LA1010 PWM outputs.

**Workflow**
- Before any task is done, run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and `cargo test`.
- Commit messages: imperative subject, no AI attribution.

**Additions the spec allows, decided here**
- `usb` decoder options `packets` (also print each packet) and `naks` (show NAKed transactions; by default they are counted and summarised at the end, to keep output readable for agents).
- `measure` also reports `max_pulse_s`; the bandwidth matrix uses it to detect gaps.
- `info --json` keys: `model`, `revision`, `magic`, `magic2`, `manufactured`, `bitstream`, `fx2_uploaded`, `fpga_uploaded` (true when this call had to load it), `pins`, `firmware_dirs`.
- `capture --timeout`.

## Review Focus

1. **Edges split across USB batches mid-frame.** A decoder fed one edge at a time must produce exactly the same events as one fed the whole stream. Batch-invariance tests in Tasks 5–9.
2. **Dead or stuck lines, and triggers that never fire.** `measure` reports `static low/high`, decoders print nothing, exit 0. An unfired trigger exits 3 after `--timeout`. Tests in Tasks 3, 5 and 16; checked on hardware in Task 17.
3. **Rates that 800 MHz can't produce exactly, or are out of range.** Snap with a stderr note. Above 100 MHz or below ~12.2 kHz is a usage error (exit 1). Tests in Task 1.
4. **stdout closed early (`la1010 monitor … | head -1`).** Exit 0 quietly, with the device halted. Test in Task 16 for `decode`; checked by hand on hardware in Task 17.
5. **USB D+/D− not switching on the same sample** (1–2-sample SE0/SE1 glitches at J↔K transitions). These must not break packet decoding. Test in Task 9.

```rust
use std::fmt;

#[derive(Debug)]
pub enum Error {
    /// Bad arguments or options (exit 1).
    Usage(String),
    /// Device missing, USB failure, overrun (exit 2).
    Device(String),
    /// Firmware missing or unparsable (exit 2).
    Firmware(String),
    /// Trigger, --until or --count not reached (exit 3).
    NoResult(String),
    /// File or stream I/O (exit 2).
    Io(std::io::Error),
}

pub type Result<T> = std::result::Result<T, Error>;

impl Error {
    pub fn exit_code(&self) -> i32 {
        match self {
            Error::Usage(_) => 1,
            Error::NoResult(_) => 3,
            Error::Device(_) | Error::Firmware(_) | Error::Io(_) => 2,
        }
    }
}

impl fmt::Display for Error {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            Error::Usage(m) | Error::Device(m) | Error::Firmware(m) | Error::NoResult(m) => {
                f.write_str(m)
            }
            Error::Io(e) => write!(f, "{e}"),
        }
    }
}

impl std::error::Error for Error {}

impl From<std::io::Error> for Error {
    fn from(e: std::io::Error) -> Self {
        Error::Io(e)
    }
}
```

```rust
use std::time::Duration;

use crate::error::{Error, Result};

/// FPGA base clock; sample rate = BASE_CLOCK / divider.
pub const BASE_CLOCK: f64 = 800e6;
/// LA1010 maximum sample rate.
pub const MAX_RATE: f64 = 100e6;
/// Highest rate x channels product verified lossless on hardware (bits/s).
pub const VERIFIED_BPS: f64 = 200e6;

/// Parse a positive number with optional k/M/G suffix.
pub fn parse_si(s: &str) -> Option<f64> {
    let s = s.trim();
    let (num, mult) = match s.chars().last()? {
        'k' | 'K' => (&s[..s.len() - 1], 1e3),
        'M' => (&s[..s.len() - 1], 1e6),
        'G' => (&s[..s.len() - 1], 1e9),
        _ => (s, 1.0),
    };
    num.parse::<f64>()
        .ok()
        .filter(|v| v.is_finite() && *v > 0.0)
        .map(|v| v * mult)
}

pub fn parse_rate(s: &str) -> Result<f64> {
    let t = s.trim();
    let t = t.strip_suffix("Hz").or_else(|| t.strip_suffix("hz")).unwrap_or(t);
    parse_si(t).ok_or_else(|| Error::Usage(format!("invalid rate '{s}' (examples: 100M, 24M, 500k)")))
}

/// Snap a requested rate to BASE_CLOCK / n. Returns (rate, divider).
pub fn snap_rate(want: f64) -> Result<(f64, u16)> {
    if want > MAX_RATE * 1.0001 {
        return Err(Error::Usage(format!("rate {} exceeds the LA1010 maximum of 100 MHz", fmt_hz(want))));
    }
    let n = (BASE_CLOCK / want).round();
    if n > f64::from(u16::MAX) {
        return Err(Error::Usage(format!(
            "rate {} is below the minimum of {}",
            fmt_hz(want),
            fmt_hz(BASE_CLOCK / f64::from(u16::MAX))
        )));
    }
    let n = (n as u16).max(8);
    Ok((BASE_CLOCK / f64::from(n), n))
}

pub fn parse_duration(s: &str) -> Result<Duration> {
    let t = s.trim();
    let bad = || Error::Usage(format!("invalid duration '{s}' (examples: 500ms, 2s, 10us)"));
    let (num, scale) = if let Some(n) = t.strip_suffix("ns") {
        (n, 1e-9)
    } else if let Some(n) = t.strip_suffix("us") {
        (n, 1e-6)
    } else if let Some(n) = t.strip_suffix("ms") {
        (n, 1e-3)
    } else if let Some(n) = t.strip_suffix("min") {
        (n, 60.0)
    } else if let Some(n) = t.strip_suffix('s') {
        (n, 1.0)
    } else {
        (t, 1.0)
    };
    let v: f64 = num.trim().parse().map_err(|_| bad())?;
    if !v.is_finite() || v < 0.0 {
        return Err(bad());
    }
    Ok(Duration::from_nanos((v * scale * 1e9).round() as u64))
}

/// Parse "0-3,8" into a channel bitmask.
pub fn parse_channels(s: &str) -> Result<u16> {
    let bad = || Error::Usage(format!("invalid channel list '{s}' (examples: 0-3, 0,2,5, 0-15)"));
    let ch = |x: &str| x.trim().parse::<u8>().ok().filter(|c| *c < 16).ok_or_else(bad);
    let mut mask = 0u16;
    for part in s.split(',') {
        let (a, b) = match part.split_once('-') {
            Some((a, b)) => (ch(a)?, ch(b)?),
            None => (ch(part)?, ch(part)?),
        };
        if a > b {
            return Err(bad());
        }
        for c in a..=b {
            mask |= 1 << c;
        }
    }
    Ok(mask)
}

/// "12.345678ms" below one second, "1.000123s" above.
pub fn format_time(t: f64) -> String {
    if t.abs() < 1.0 { format!("{:.6}ms", t * 1e3) } else { format!("{t:.6}s") }
}

pub fn fmt_hz(hz: f64) -> String {
    if hz >= 1e6 {
        format!("{:.3} MHz", hz / 1e6)
    } else if hz >= 1e3 {
        format!("{:.3} kHz", hz / 1e3)
    } else {
        format!("{hz:.3} Hz")
    }
}
```

```rust
//! Turn the LA1010 bulk stream into level-change edges.
//!
//! Stream format (verified on hardware): u16 little-endian words, one per enabled
//! channel in ascending channel order, repeating. Each word holds 16 consecutive
//! samples of one channel; bit 0 is the earliest.

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Edge {
    pub sample: u64,
    pub ch: u8,
    pub level: bool,
}

pub struct Deinterleaver {
    channels: Vec<u8>,
    words: Vec<u16>,
    carry: Option<u8>,
    block: u64,
    levels: u16,
}

impl Deinterleaver {
    pub fn new(mask: u16) -> Self {
        assert!(mask != 0, "at least one channel");
        let channels: Vec<u8> = (0..16).filter(|c| mask >> c & 1 == 1).collect();
        Deinterleaver { words: Vec::with_capacity(channels.len()), channels, carry: None, block: 0, levels: 0 }
    }

    /// Number of complete samples decoded so far.
    pub fn samples(&self) -> u64 {
        self.block * 16
    }

    pub fn push(&mut self, bytes: &[u8], out: &mut Vec<Edge>) {
        let mut i = 0;
        if let Some(lo) = self.carry.take() {
            let Some(&hi) = bytes.first() else {
                self.carry = Some(lo);
                return;
            };
            self.word(u16::from_le_bytes([lo, hi]), out);
            i = 1;
        }
        while i + 1 < bytes.len() {
            self.word(u16::from_le_bytes([bytes[i], bytes[i + 1]]), out);
            i += 2;
        }
        if i < bytes.len() {
            self.carry = Some(bytes[i]);
        }
    }

    fn word(&mut self, w: u16, out: &mut Vec<Edge>) {
        self.words.push(w);
        if self.words.len() == self.channels.len() {
            self.emit_block(out);
            self.words.clear();
        }
    }

    fn emit_block(&mut self, out: &mut Vec<Edge>) {
        let base = self.block * 16;
        let start = out.len();
        for (k, &ch) in self.channels.iter().enumerate() {
            let w = self.words[k];
            let prev = (self.levels >> ch) & 1;
            let mut diff = w ^ ((w << 1) | prev);
            if self.block == 0 {
                diff |= 1;
            }
            while diff != 0 {
                let bit = diff.trailing_zeros();
                out.push(Edge { sample: base + u64::from(bit), ch, level: (w >> bit) & 1 == 1 });
                diff &= diff - 1;
            }
            self.levels = (self.levels & !(1 << ch)) | ((w >> 15) << ch);
        }
        if self.channels.len() > 1 {
            out[start..].sort_unstable_by_key(|e| (e.sample, e.ch));
        }
        self.block += 1;
    }
}
```

```rust
//! Software trigger and capture window. The LA1010 streams without hardware
//! trigger, so the host selects the window and rebases sample numbers to it.

use std::collections::VecDeque;

use crate::error::{Error, Result};
use crate::stream::Edge;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Cond {
    Rise,
    Fall,
    High,
    Low,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Trigger(pub Vec<(u8, Cond)>);

impl Trigger {
    /// "0:rise", "3:fall,1:high". At most one rise/fall condition.
    pub fn parse(s: &str) -> Result<Self> {
        let mut conds = Vec::new();
        for part in s.split(',') {
            let (ch, c) = part
                .split_once(':')
                .ok_or_else(|| Error::Usage(format!("trigger '{part}': expected CH:rise|fall|high|low")))?;
            let ch: u8 = ch
                .trim()
                .parse()
                .ok()
                .filter(|c| *c < 16)
                .ok_or_else(|| Error::Usage(format!("trigger channel '{ch}' must be 0-15")))?;
            let cond = match c.trim() {
                "rise" | "r" => Cond::Rise,
                "fall" | "f" => Cond::Fall,
                "high" | "1" => Cond::High,
                "low" | "0" => Cond::Low,
                o => return Err(Error::Usage(format!("trigger condition '{o}': use rise, fall, high or low"))),
            };
            conds.push((ch, cond));
        }
        if conds.iter().filter(|(_, c)| matches!(c, Cond::Rise | Cond::Fall)).count() > 1 {
            return Err(Error::Usage("trigger: at most one rise/fall condition".into()));
        }
        Ok(Trigger(conds))
    }

    pub fn mask(&self) -> u16 {
        self.0.iter().fold(0, |m, (ch, _)| m | 1 << ch)
    }

    fn levels_ok(&self, levels: u16) -> bool {
        self.0.iter().all(|&(ch, c)| match c {
            Cond::High => levels >> ch & 1 == 1,
            Cond::Low => levels >> ch & 1 == 0,
            Cond::Rise | Cond::Fall => true,
        })
    }

    fn fires(&self, group: &[Edge], before: u16, after: u16, first: bool) -> bool {
        if !self.levels_ok(after) {
            return false;
        }
        match self.0.iter().find(|(_, c)| matches!(c, Cond::Rise | Cond::Fall)) {
            Some(&(ch, c)) => !first && group.iter().any(|e| e.ch == ch && e.level == (c == Cond::Rise)),
            None => first || !self.levels_ok(before),
        }
    }
}

fn set(levels: u16, ch: u8, level: bool) -> u16 {
    if level { levels | 1 << ch } else { levels & !(1 << ch) }
}

pub struct Window {
    trigger: Option<Trigger>,
    mask: u16,
    pre: u64,
    len: u64,
    levels: u16,
    hist: VecDeque<Edge>,
    hist_levels: u16,
    start: Option<u64>,
    trig: Option<u64>,
    seen_first: bool,
}

impl Window {
    /// `pre`: samples kept before the trigger; `len`: total output samples
    /// (`u64::MAX` = unbounded). Without trigger the window starts at sample 0.
    pub fn new(mask: u16, trigger: Option<Trigger>, pre: u64, len: u64) -> Self {
        let start = if trigger.is_none() { Some(0) } else { None };
        Window {
            trigger,
            mask,
            pre,
            len,
            levels: 0,
            hist: VecDeque::new(),
            hist_levels: 0,
            start,
            trig: None,
            seen_first: false,
        }
    }

    pub fn triggered(&self) -> bool {
        self.start.is_some()
    }

    pub fn trigger_sample(&self) -> Option<u64> {
        Some(self.trig? - self.start?)
    }

    pub fn output_len(&self, now: u64) -> u64 {
        self.start.map_or(0, |s| now.saturating_sub(s).min(self.len))
    }

    pub fn push(&mut self, edges: &[Edge], now: u64, out: &mut Vec<Edge>) -> bool {
        let mut i = 0;
        while i < edges.len() {
            if let Some(s) = self.start {
                for e in &edges[i..] {
                    if e.sample - s >= self.len {
                        break;
                    }
                    out.push(Edge { sample: e.sample - s, ..*e });
                }
                break;
            }
            let sample = edges[i].sample;
            let j = edges[i..].iter().position(|e| e.sample != sample).map_or(edges.len(), |k| i + k);
            let group = &edges[i..j];
            let before = self.levels;
            for e in group {
                self.levels = set(self.levels, e.ch, e.level);
                self.hist.push_back(*e);
            }
            let first = !self.seen_first;
            self.seen_first = true;
            let cutoff = sample.saturating_sub(self.pre);
            while let Some(f) = self.hist.front().copied() {
                if f.sample >= cutoff {
                    break;
                }
                self.hist_levels = set(self.hist_levels, f.ch, f.level);
                self.hist.pop_front();
            }
            let fires = self.trigger.as_ref().is_some_and(|t| t.fires(group, before, self.levels, first));
            if fires {
                self.start = Some(cutoff);
                self.trig = Some(sample);
                let mut lv = self.hist_levels;
                let at_cutoff = self.hist.iter().take_while(|e| e.sample == cutoff).count();
                for e in self.hist.iter().take(at_cutoff) {
                    lv = set(lv, e.ch, e.level);
                }
                for ch in (0..16u8).filter(|c| self.mask >> c & 1 == 1) {
                    out.push(Edge { sample: 0, ch, level: lv >> ch & 1 == 1 });
                }
                for e in self.hist.drain(..).skip(at_cutoff) {
                    out.push(Edge { sample: e.sample - cutoff, ..e });
                }
            }
            i = j;
        }
        self.start.is_some_and(|s| now.saturating_sub(s) >= self.len)
    }
}
```

```rust
//! Decoded events and their text / NDJSON rendering.

use std::io::Write;

use serde_json::{Map, Value, json};

use crate::error::{Error, Result};
use crate::units::format_time;

#[derive(Clone, Debug, PartialEq)]
pub struct Event {
    pub sample: u64,
    pub proto: &'static str,
    pub kind: &'static str,
    pub text: String,
    pub fields: Map<String, Value>,
}

impl Event {
    pub fn new(sample: u64, proto: &'static str, kind: &'static str, text: impl Into<String>) -> Self {
        Event { sample, proto, kind, text: text.into(), fields: Map::new() }
    }

    pub fn with(mut self, key: &str, v: impl Into<Value>) -> Self {
        self.fields.insert(key.to_string(), v.into());
        self
    }
}

pub struct Printer<W: Write> {
    out: W,
    json: bool,
    rate: f64,
    origin: u64,
}

impl<W: Write> Printer<W> {
    pub fn new(out: W, json: bool, rate: f64) -> Self {
        Printer { out, json, rate, origin: 0 }
    }

    /// Sample that maps to t = 0 (the trigger position).
    pub fn set_origin(&mut self, origin: u64) {
        self.origin = origin;
    }

    pub fn render(&self, e: &Event) -> String {
        let t = (e.sample as f64 - self.origin as f64) / self.rate;
        if !self.json {
            return format!("{:<14} {:<7} {}", format_time(t), e.proto, e.text);
        }
        let mut m = Map::new();
        m.insert("t".into(), json!((t * 1e9).round() / 1e9));
        m.insert("sample".into(), json!(e.sample));
        m.insert("proto".into(), json!(e.proto));
        m.insert("kind".into(), json!(e.kind));
        for (k, v) in &e.fields {
            m.insert(k.clone(), v.clone());
        }
        m.insert("text".into(), json!(e.text));
        Value::Object(m).to_string()
    }

    pub fn print(&mut self, e: &Event) -> Result<String> {
        let line = self.render(e);
        writeln!(self.out, "{line}")?;
        Ok(line)
    }

    pub fn flush(&mut self) -> Result<()> {
        Ok(self.out.flush()?)
    }

    pub fn into_inner(self) -> W {
        self.out
    }
}

pub fn error_json(e: &Error) -> String {
    json!({"error": e.to_string(), "code": e.exit_code()}).to_string()
}
```

```rust
//! Per-channel frequency, duty cycle and pulse statistics.

use crate::output::Event;
use crate::stream::Edge;
use crate::units::format_time;

#[derive(Clone, Debug, PartialEq)]
pub struct Stats {
    pub ch: u8,
    pub edges: u64,
    pub freq_hz: Option<f64>,
    pub duty: Option<f64>,
    pub min_pulse_s: Option<f64>,
    pub max_pulse_s: Option<f64>,
    /// Static level when the channel never changed; None if it toggled or saw no data.
    pub level: Option<bool>,
}

#[derive(Clone, Copy, Default)]
struct St {
    level: Option<bool>,
    last: Option<u64>,
    edges: u64,
    first_rise: Option<u64>,
    last_rise: Option<u64>,
    rises: u64,
    high_since: Option<u64>,
    pending_high: u64,
    high: u64,
    min_pulse: Option<u64>,
    max_pulse: Option<u64>,
}

pub struct Measure {
    mask: u16,
    rate: f64,
    st: [St; 16],
}

impl Measure {
    pub fn new(mask: u16, rate: f64) -> Self {
        Measure { mask, rate, st: [St::default(); 16] }
    }

    pub fn feed(&mut self, edges: &[Edge]) {
        for e in edges {
            let s = &mut self.st[e.ch as usize];
            let Some(prev) = s.level else {
                s.level = Some(e.level);
                continue;
            };
            if prev == e.level {
                continue;
            }
            s.edges += 1;
            if let Some(l) = s.last {
                let d = e.sample - l;
                s.min_pulse = Some(s.min_pulse.map_or(d, |m| m.min(d)));
                s.max_pulse = Some(s.max_pulse.map_or(d, |m| m.max(d)));
            }
            s.last = Some(e.sample);
            if e.level {
                if s.first_rise.is_none() {
                    s.first_rise = Some(e.sample);
                } else {
                    s.high = s.pending_high;
                }
                s.last_rise = Some(e.sample);
                s.rises += 1;
                s.high_since = Some(e.sample);
            } else if let Some(h) = s.high_since.take() {
                s.pending_high += e.sample - h;
            }
            s.level = Some(e.level);
        }
    }

    pub fn finish(&self) -> Vec<Stats> {
        (0..16u8)
            .filter(|c| self.mask >> c & 1 == 1)
            .map(|ch| {
                let s = &self.st[ch as usize];
                let span = match (s.first_rise, s.last_rise) {
                    (Some(a), Some(b)) if s.rises >= 2 => Some((b - a) as f64),
                    _ => None,
                };
                Stats {
                    ch,
                    edges: s.edges,
                    freq_hz: span.map(|sp| (s.rises - 1) as f64 * self.rate / sp),
                    duty: span.map(|sp| s.high as f64 / sp),
                    min_pulse_s: s.min_pulse.map(|p| p as f64 / self.rate),
                    max_pulse_s: s.max_pulse.map(|p| p as f64 / self.rate),
                    level: if s.edges == 0 { s.level } else { None },
                }
            })
            .collect()
    }

    pub fn events(stats: &[Stats]) -> Vec<Event> {
        stats
            .iter()
            .map(|s| {
                let text = match (s.edges, s.level) {
                    (0, Some(l)) => format!("ch{} static {}", s.ch, if l { "high" } else { "low" }),
                    (0, None) => format!("ch{} no data", s.ch),
                    _ => {
                        let mut t = String::new();
                        if let (Some(f), Some(d)) = (s.freq_hz, s.duty) {
                            t = format!("{f:.3} Hz duty {:.1}% ", d * 100.0);
                        }
                        let p = |v: Option<f64>| v.map_or("-".into(), format_time);
                        format!(
                            "ch{} {t}edges {} pulse min {} max {}",
                            s.ch,
                            s.edges,
                            p(s.min_pulse_s),
                            p(s.max_pulse_s)
                        )
                    }
                };
                Event::new(0, "measure", "channel", text)
                    .with("ch", s.ch)
                    .with("edges", s.edges)
                    .with("freq_hz", s.freq_hz)
                    .with("duty", s.duty)
                    .with("min_pulse_s", s.min_pulse_s)
                    .with("max_pulse_s", s.max_pulse_s)
                    .with("level", s.level)
            })
            .collect()
    }
}
```

```rust
//! Waveform generators used by tests. Not a stable API.

use crate::stream::Edge;

#[derive(Default)]
pub struct Wave {
    sets: Vec<(u64, u8, bool)>,
}

impl Wave {
    pub fn new() -> Self {
        Self::default()
    }

    pub fn set(&mut self, sample: u64, ch: u8, level: bool) {
        self.sets.push((sample, ch, level));
    }

    /// Sorted edges. The first set per channel is its initial level; later sets
    /// produce an edge only when the level changes. A later set at the same
    /// (sample, ch) overrides an earlier one.
    pub fn edges(&self) -> Vec<Edge> {
        let mut s = self.sets.clone();
        s.sort_by_key(|&(t, ch, _)| (t, ch));
        let mut last: [Option<bool>; 16] = [None; 16];
        let mut out: Vec<Edge> = Vec::new();
        for (t, ch, level) in s {
            if let Some(prev) = out.last_mut().filter(|e| e.sample == t && e.ch == ch) {
                prev.level = level;
                last[ch as usize] = Some(level);
                continue;
            }
            if last[ch as usize] != Some(level) {
                out.push(Edge { sample: t, ch, level });
                last[ch as usize] = Some(level);
            }
        }
        out
    }
}

/// One UART frame, LSB first: start, data, optional parity, stop bits.
pub fn uart_bits(value: u16, bits: u8, parity: Option<bool>, stops: u8) -> Vec<bool> {
    let mut v = vec![false];
    for i in 0..bits {
        v.push(value >> i & 1 == 1);
    }
    if let Some(even) = parity {
        let ones = (value & ((1 << bits) - 1)).count_ones();
        v.push((ones % 2 == 1) == even);
    }
    v.extend(std::iter::repeat_n(true, stops as usize));
    v
}

/// Drive `bits` on `ch` from `start`, `bit` samples per bit. Returns the end sample.
pub fn uart_frame(w: &mut Wave, ch: u8, start: f64, bit: f64, bits: &[bool]) -> f64 {
    for (i, &b) in bits.iter().enumerate() {
        w.set((start + i as f64 * bit).round() as u64, ch, b);
    }
    start + bits.len() as f64 * bit
}
```

```rust
//! Protocol decoders. Each consumes sorted edges (see `stream::Edge`) and emits events.

pub mod uart;

use std::str::FromStr;

use crate::error::{Error, Result};
use crate::output::Event;
use crate::stream::Edge;
use crate::units::{MAX_RATE, parse_si};

pub trait Decoder {
    fn feed(&mut self, edges: &[Edge], out: &mut Vec<Event>);
    /// `end`: last sample of the capture (exclusive).
    fn finish(&mut self, end: u64, out: &mut Vec<Event>);
}

pub struct OptInfo {
    pub name: &'static str,
    pub help: &'static str,
    pub default: Option<&'static str>,
    pub required: bool,
    pub channel: bool,
}

pub struct Info {
    pub name: &'static str,
    pub help: &'static str,
    pub opts: &'static [OptInfo],
}

pub fn catalog() -> Vec<&'static Info> {
    vec![&uart::INFO]
}

pub fn info(name: &str) -> Result<&'static Info> {
    catalog().into_iter().find(|i| i.name == name).ok_or_else(|| {
        let names: Vec<_> = catalog().iter().map(|i| i.name).collect();
        Error::Usage(format!("unknown decoder '{name}' (available: {})", names.join(", ")))
    })
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Spec {
    pub name: String,
    pub opts: Vec<(String, String)>,
}

impl Spec {
    /// "uart:rx=0,baud=115200,invert". Validated against the catalog.
    pub fn parse(s: &str) -> Result<Spec> {
        let (name, rest) = s.split_once(':').unwrap_or((s, ""));
        let name = name.trim();
        if name.is_empty() {
            return Err(Error::Usage(format!(
                "decoder spec '{s}': missing name (example: uart:rx=0,baud=115200)"
            )));
        }
        let opts = rest
            .split(',')
            .map(str::trim)
            .filter(|p| !p.is_empty())
            .map(|p| match p.split_once('=') {
                Some((k, v)) => (k.trim().to_string(), v.trim().to_string()),
                None => (p.to_string(), String::new()),
            })
            .collect();
        let spec = Spec { name: name.to_string(), opts };
        spec.check(info(&spec.name)?)?;
        Ok(spec)
    }

    fn check(&self, info: &Info) -> Result<()> {
        for (k, _) in &self.opts {
            if !info.opts.iter().any(|o| o.name == k) {
                let known: Vec<_> = info.opts.iter().map(|o| o.name).collect();
                return Err(self.usage(format!("unknown option '{k}' (options: {})", known.join(", "))));
            }
        }
        for o in info.opts.iter().filter(|o| o.required) {
            if self.get(o.name).is_none() {
                return Err(self.usage(format!("missing required option {}=", o.name)));
            }
        }
        for o in info.opts.iter().filter(|o| o.channel) {
            self.ch(o.name)?;
        }
        Ok(())
    }

    pub fn usage(&self, msg: impl std::fmt::Display) -> Error {
        Error::Usage(format!("{}: {msg}", self.name))
    }

    pub fn get(&self, k: &str) -> Option<&str> {
        self.opts.iter().rev().find(|(n, _)| n == k).map(|(_, v)| v.as_str())
    }

    pub fn flag(&self, k: &str) -> bool {
        matches!(self.get(k), Some("" | "1" | "true" | "yes"))
    }

    pub fn ch(&self, k: &str) -> Result<Option<u8>> {
        self.get(k)
            .map(|v| {
                v.parse::<u8>()
                    .ok()
                    .filter(|c| *c < 16)
                    .ok_or_else(|| self.usage(format!("{k}={v} is not a channel 0-15")))
            })
            .transpose()
    }

    pub fn num<T: FromStr>(&self, k: &str, default: T) -> Result<T> {
        match self.get(k) {
            None => Ok(default),
            Some(v) => v.parse().map_err(|_| self.usage(format!("invalid {k}={v}"))),
        }
    }

    pub fn channel_mask(&self) -> Result<u16> {
        let mut m = 0;
        for o in info(&self.name)?.opts.iter().filter(|o| o.channel) {
            if let Some(c) = self.ch(o.name)? {
                m |= 1 << c;
            }
        }
        Ok(m)
    }
}

        n => return Err(Error::Usage(format!("unknown decoder '{n}'"))),

}

/// Sample rate to use when the user gives none.
pub fn recommended_rate(spec: &Spec) -> Result<f64> {
    let r = match spec.name.as_str() {
        "uart" => match spec.get("baud") {
            None | Some("auto") => 10e6,
            Some(b) => 16.0 * parse_si(b).ok_or_else(|| spec.usage(format!("invalid baud={b}")))?,
        },
        n => return Err(Error::Usage(format!("unknown decoder '{n}'"))),
    };
    Ok(r.clamp(1e6, MAX_RATE))
}

/// Line levels with all edges of one sample applied together.
#[derive(Default)]
pub struct Lines {
    levels: u16,
    known: u16,
}

pub struct Step {
    pub sample: u64,
    pub before: u16,
    pub after: u16,
    /// Channels whose level was known before this sample.
    pub known: u16,
    /// Channels with an edge at this sample.
    pub touched: u16,
}

impl Step {
    pub fn high(&self, ch: u8) -> bool {
        self.after >> ch & 1 == 1
    }
    pub fn was_high(&self, ch: u8) -> bool {
        self.before >> ch & 1 == 1
    }
    pub fn was_known(&self, ch: u8) -> bool {
        self.known >> ch & 1 == 1
    }
    pub fn touched(&self, ch: u8) -> bool {
        self.touched >> ch & 1 == 1
    }
    /// First level ever seen for `ch`.
    pub fn first(&self, ch: u8) -> bool {
        self.touched(ch) && !self.was_known(ch)
    }
    pub fn rose(&self, ch: u8) -> bool {
        self.was_known(ch) && !self.was_high(ch) && self.high(ch)
    }
    pub fn fell(&self, ch: u8) -> bool {
        self.was_known(ch) && self.was_high(ch) && !self.high(ch)
    }
}

impl Lines {
    pub fn steps(&mut self, edges: &[Edge], mut f: impl FnMut(&Step)) {
        let mut i = 0;
        while i < edges.len() {
            let sample = edges[i].sample;
            let mut st = Step { sample, before: self.levels, after: self.levels, known: self.known, touched: 0 };
            while i < edges.len() && edges[i].sample == sample {
                let e = edges[i];
                let bit = 1u16 << e.ch;
                st.after = if e.level { st.after | bit } else { st.after & !bit };
                st.touched |= bit;
                i += 1;
            }
            self.levels = st.after;
            self.known |= st.touched;
            f(&st);
        }
    }
}
```

```rust
//! Asynchronous serial. Each line is sampled at bit centres from the start-bit edge.

use crate::decode::{Decoder, Info, Lines, OptInfo, Spec};
use crate::error::Result;
use crate::output::Event;
use crate::stream::Edge;
use crate::units::parse_si;

pub const INFO: Info = Info {
    name: "uart",
    help: "asynchronous serial (TTL/RS-232 UART)",
    opts: &[
        OptInfo { name: "rx", help: "receive line channel", default: None, required: false, channel: true },
        OptInfo { name: "tx", help: "transmit line channel", default: None, required: false, channel: true },
        OptInfo {
            name: "baud",
            help: "baud rate, or auto (estimated from the shortest pulse)",
            default: Some("auto"),
            required: false,
            channel: false,
        },
        OptInfo { name: "bits", help: "data bits 5-9", default: Some("8"), required: false, channel: false },
        OptInfo { name: "parity", help: "n, e or o", default: Some("n"), required: false, channel: false },
        OptInfo { name: "stop", help: "stop bits 1, 1.5 or 2", default: Some("1"), required: false, channel: false },
        OptInfo { name: "invert", help: "inverted logic (idle low)", default: None, required: false, channel: false },
    ],
};

const STANDARD: [f64; 22] = [
    300.0, 600.0, 1200.0, 2400.0, 4800.0, 9600.0, 14400.0, 19200.0, 28800.0, 38400.0, 57600.0, 76800.0,
    115200.0, 230400.0, 250000.0, 460800.0, 500000.0, 921600.0, 1e6, 1.5e6, 2e6, 3e6,
];
const AUTO_EDGES: usize = 256;

#[derive(Clone, Copy, PartialEq, Eq)]
enum Parity {
    None,
    Even,
    Odd,
}

#[derive(Clone, Copy)]
struct Cfg {
    bits: u32,
    parity: Parity,
    stops: u32,
    invert: bool,
    /// Samples per bit; 0 until auto-baud has settled.
    bit: f64,
}

#[derive(Clone, Copy)]
enum St {
    Idle,
    /// Line low outside a frame; wait for idle (high) before the next start bit.
    Wait,
    Frame { start: f64, idx: u32, value: u16, parity_ok: bool, framing: bool },
}

struct Line {
    name: &'static str,
    ch: u8,
    st: St,
    level: Option<bool>,
}

impl Line {
    fn advance(&mut self, until: f64, cfg: &Cfg, out: &mut Vec<Event>) {
        let Some(level) = self.level else { return };
        while let St::Frame { start, idx, .. } = self.st {
            if start + (f64::from(idx) + 0.5) * cfg.bit >= until {
                return;
            }
            self.sample_bit(level, cfg, out);
        }
    }

    fn sample_bit(&mut self, level: bool, cfg: &Cfg, out: &mut Vec<Event>) {
        let St::Frame { start, mut idx, mut value, mut parity_ok, mut framing } = self.st else { return };
        let n_par = u32::from(cfg.parity != Parity::None);
        if idx == 0 {
            if level {
                self.st = St::Idle; // start bit did not hold: glitch
                return;
            }
        } else if idx <= cfg.bits {
            value |= u16::from(level) << (idx - 1);
        } else if n_par == 1 && idx == cfg.bits + 1 {
            let ones = value.count_ones() + u32::from(level);
            parity_ok = match cfg.parity {
                Parity::Even => ones % 2 == 0,
                Parity::Odd => ones % 2 == 1,
                Parity::None => true,
            };
        } else if !level {
            framing = true;
        }
        idx += 1;
        if idx < 1 + cfg.bits + n_par + cfg.stops {
            self.st = St::Frame { start, idx, value, parity_ok, framing };
            return;
        }
        out.push(self.event(start.round() as u64, value, parity_ok, framing));
        self.st = if level { St::Idle } else { St::Wait };
    }

    fn transition(&mut self, level: bool, sample: u64) {
        let first = self.level.is_none();
        self.level = Some(level);
        match self.st {
            St::Idle if first && !level => self.st = St::Wait,
            St::Idle if !level => {
                self.st = St::Frame { start: sample as f64, idx: 0, value: 0, parity_ok: true, framing: false }
            }
            St::Wait if level => self.st = St::Idle,
            _ => {}
        }
    }

    fn event(&self, sample: u64, value: u16, parity_ok: bool, framing: bool) -> Event {
        if framing && value == 0 {
            return Event::new(sample, "uart", "break", format!("{} break", self.name)).with("ch", self.name);
        }
        let text = if (0x20..0x7f).contains(&value) {
            format!("{} 0x{value:02x} '{}'", self.name, value as u8 as char)
        } else {
            format!("{} 0x{value:02x}", self.name)
        };
        let ev = if framing || !parity_ok {
            let err = if framing { "framing" } else { "parity" };
            Event::new(sample, "uart", "error", format!("{text} {err} error")).with("error", err)
        } else {
            Event::new(sample, "uart", "byte", text)
        };
        ev.with("ch", self.name).with("value", value)
    }
}

pub struct Uart {
    lines: Vec<Line>,
    state: Lines,
    cfg: Cfg,
    rate: f64,
    auto: Option<Vec<Edge>>,
}

impl Uart {
    pub fn new(spec: &Spec, rate: f64) -> Result<Self> {
        let mut lines = Vec::new();
        for name in ["rx", "tx"] {
            if let Some(ch) = spec.ch(name)? {
                lines.push(Line { name, ch, st: St::Idle, level: None });
            }
        }
        if lines.is_empty() {
            return Err(spec.usage("need rx=CH and/or tx=CH"));
        }
        let bits: u32 = spec.num("bits", 8)?;
        if !(5..=9).contains(&bits) {
            return Err(spec.usage("bits must be 5-9"));
        }
        let parity = match spec.get("parity").unwrap_or("n") {
            "n" | "none" => Parity::None,
            "e" | "even" => Parity::Even,
            "o" | "odd" => Parity::Odd,
            o => return Err(spec.usage(format!("parity={o}: use n, e or o"))),
        };
        let stops = match spec.get("stop").unwrap_or("1") {
            "1" | "1.5" => 1,
            "2" => 2,
            o => return Err(spec.usage(format!("stop={o}: use 1, 1.5 or 2"))),
        };
        let (bit, auto) = match spec.get("baud").unwrap_or("auto") {
            "auto" => (0.0, Some(Vec::new())),
            b => {
                let baud = parse_si(b).ok_or_else(|| spec.usage(format!("invalid baud={b}")))?;
                if rate < 4.0 * baud {
                    return Err(spec.usage(format!(
                        "sample rate {rate} Hz is too low for {baud} baud (need at least 4x)"
                    )));
                }
                (rate / baud, None)
            }
        };
        Ok(Uart { lines, state: Lines::default(), cfg: Cfg { bits, parity, stops, invert: spec.flag("invert"), bit }, rate, auto })
    }

    fn decode(&mut self, edges: &[Edge], out: &mut Vec<Event>) {
        if self.cfg.bit <= 0.0 {
            return;
        }
        let cfg = self.cfg;
        let lines = &mut self.lines;
        self.state.steps(edges, |st| {
            for l in lines.iter_mut() {
                if st.first(l.ch) || st.rose(l.ch) || st.fell(l.ch) {
                    l.advance(st.sample as f64, &cfg, out);
                    l.transition(st.high(l.ch) ^ cfg.invert, st.sample);
                }
            }
        });
    }

    /// Estimate the baud rate from the buffered edges, then decode them.
    fn settle(&mut self, out: &mut Vec<Event>) {
        let Some(buf) = self.auto.take() else { return };
        let mut last: [Option<u64>; 16] = [None; 16];
        let mut seen = [0u32; 16];
        let mut min = u64::MAX;
        for e in buf.iter().filter(|e| self.lines.iter().any(|l| l.ch == e.ch)) {
            let c = e.ch as usize;
            seen[c] += 1;
            if seen[c] >= 3 {
                if let Some(p) = last[c] {
                    let d = e.sample - p;
                    if d >= 2 {
                        min = min.min(d);
                    }
                }
            }
            last[c] = Some(e.sample);
        }
        if min == u64::MAX {
            out.push(Event::new(0, "uart", "info", "baud auto-detection failed: not enough edges"));
            return;
        }
        let raw = self.rate / min as f64;
        let baud = STANDARD.iter().copied().find(|b| (raw / b - 1.0).abs() < 0.04).unwrap_or(raw.round());
        self.cfg.bit = self.rate / baud;
        out.push(Event::new(0, "uart", "info", format!("baud {baud} (auto)")).with("baud", baud));
        self.decode(&buf, out);
    }
}

impl Decoder for Uart {
    fn feed(&mut self, edges: &[Edge], out: &mut Vec<Event>) {
        if let Some(buf) = &mut self.auto {
            buf.extend_from_slice(edges);
            let n = buf.iter().filter(|e| self.lines.iter().any(|l| l.ch == e.ch)).count();
            if n >= AUTO_EDGES {
                self.settle(out);
            }
            return;
        }
        self.decode(edges, out);
    }

    fn finish(&mut self, end: u64, out: &mut Vec<Event>) {
        if self.auto.is_some() {
            self.settle(out);
        }
        let cfg = self.cfg;
        if cfg.bit > 0.0 {
            for l in &mut self.lines {
                l.advance(end as f64, &cfg, out);
            }
        }
    }
}
```

```rust
/// START: SDA falls while SCL is high, then SCL goes low. `h` = half clock period.
pub fn i2c_start(w: &mut Wave, scl: u8, sda: u8, t: u64, h: u64) -> u64 {
    w.set(t, sda, false);
    w.set(t + h, scl, false);
    t + h
}

/// 8 data bits MSB first plus the ACK bit (ack = SDA low on the 9th clock).
pub fn i2c_byte(w: &mut Wave, scl: u8, sda: u8, mut t: u64, h: u64, byte: u8, ack: bool) -> u64 {
    for i in 0..9 {
        let bit = if i < 8 { byte >> (7 - i) & 1 == 1 } else { !ack };
        w.set(t + h / 2, sda, bit);
        w.set(t + h, scl, true);
        w.set(t + 2 * h, scl, false);
        t += 2 * h;
    }
    t
}

pub fn i2c_restart(w: &mut Wave, scl: u8, sda: u8, t: u64, h: u64) -> u64 {
    w.set(t + h / 2, sda, true);
    w.set(t + h, scl, true);
    w.set(t + 2 * h, sda, false);
    w.set(t + 3 * h, scl, false);
    t + 3 * h
}

pub fn i2c_stop(w: &mut Wave, scl: u8, sda: u8, t: u64, h: u64) -> u64 {
    w.set(t + h / 2, sda, false);
    w.set(t + h, scl, true);
    w.set(t + 2 * h, sda, true);
    t + 2 * h
}
```

```rust
//! I²C: START/STOP from SDA edges while SCL is high, bits sampled on SCL rising edges.

use crate::decode::{Decoder, Info, Lines, OptInfo, Spec};
use crate::error::Result;
use crate::output::Event;
use crate::stream::Edge;

pub const INFO: Info = Info {
    name: "i2c",
    help: "I2C / TWI / SMBus (7-bit addressing)",
    opts: &[
        OptInfo { name: "scl", help: "clock channel", default: None, required: true, channel: true },
        OptInfo { name: "sda", help: "data channel", default: None, required: true, channel: true },
    ],
};

pub struct I2c {
    scl: u8,
    sda: u8,
    lines: Lines,
    active: bool,
    first: bool,
    nbits: u8,
    byte: u8,
    byte_start: u64,
}

impl I2c {
    pub fn new(spec: &Spec) -> Result<Self> {
        let req = |k: &str| spec.ch(k)?.ok_or_else(|| spec.usage(format!("missing {k}=")));
        Ok(I2c {
            scl: req("scl")?,
            sda: req("sda")?,
            lines: Lines::default(),
            active: false,
            first: false,
            nbits: 0,
            byte: 0,
            byte_start: 0,
        })
    }
}

fn ack_text(ack: bool) -> &'static str {
    if ack { "ACK" } else { "NACK" }
}

impl Decoder for I2c {
    fn feed(&mut self, edges: &[Edge], out: &mut Vec<Event>) {
        let I2c { scl, sda, lines, active, first, nbits, byte, byte_start } = self;
        let (scl, sda) = (*scl, *sda);
        lines.steps(edges, |st| {
            if st.was_known(scl) && st.was_high(scl) && st.high(scl) {
                if st.fell(sda) {
                    let text = if *active { "Sr" } else { "S" };
                    out.push(Event::new(st.sample, "i2c", "start", text));
                    *active = true;
                    *first = true;
                    *nbits = 0;
                    *byte = 0;
                    return;
                }
                if st.rose(sda) && *active {
                    out.push(Event::new(st.sample, "i2c", "stop", "P"));
                    *active = false;
                    return;
                }
            }
            if !*active || !st.rose(scl) {
                return;
            }
            let bit = st.high(sda);
            if *nbits == 0 {
                *byte_start = st.sample;
            }
            if *nbits < 8 {
                *byte = *byte << 1 | u8::from(bit);
                *nbits += 1;
                return;
            }
            let ack = !bit;
            let ev = if *first {
                let (addr, rw) = (*byte >> 1, if *byte & 1 == 1 { "R" } else { "W" });
                Event::new(*byte_start, "i2c", "address", format!("{rw} 0x{addr:02x} {}", ack_text(ack)))
                    .with("addr", addr)
                    .with("rw", rw)
            } else {
                Event::new(*byte_start, "i2c", "data", format!("data 0x{:02x} {}", *byte, ack_text(ack)))
                    .with("value", *byte)
            };
            out.push(ev.with("ack", ack));
            *nbits = 0;
            *byte = 0;
            *first = false;
        });
    }

    fn finish(&mut self, _end: u64, _out: &mut Vec<Event>) {}
}
```

```rust
/// One SPI word. CPHA=0: data set, then leading edge (sample), then trailing edge.
/// CPHA=1: leading edge, data set, then trailing edge (sample). Returns end time.
#[allow(clippy::too_many_arguments)]
pub fn spi_word(
    w: &mut Wave, clk: u8, mosi: u8, miso: u8, mut t: u64, h: u64, mode: u8, bits: u8, lsb: bool, vm: u32, vs: u32,
) -> u64 {
    let cpol = mode >> 1 & 1 == 1;
    let cpha = mode & 1 == 1;
    for i in 0..bits {
        let k = if lsb { i } else { bits - 1 - i };
        let (bm, bs) = (vm >> k & 1 == 1, vs >> k & 1 == 1);
        if cpha {
            w.set(t, clk, !cpol);
            w.set(t + 1, mosi, bm);
            w.set(t + 1, miso, bs);
            w.set(t + h, clk, cpol);
        } else {
            w.set(t, mosi, bm);
            w.set(t, miso, bs);
            w.set(t + h, clk, !cpol);
            w.set(t + 2 * h, clk, cpol);
        }
        t += 2 * h;
    }
    t
}
```

```rust
//! SPI: words sampled on the mode's sampling edge, grouped into CS-delimited transfers.

use crate::decode::{Decoder, Info, Lines, OptInfo, Spec};
use crate::error::Result;
use crate::output::Event;
use crate::stream::Edge;

pub const INFO: Info = Info {
    name: "spi",
    help: "SPI (modes 0-3, optional chip select)",
    opts: &[
        OptInfo { name: "clk", help: "clock channel", default: None, required: true, channel: true },
        OptInfo { name: "mosi", help: "controller-out channel", default: None, required: false, channel: true },
        OptInfo { name: "miso", help: "controller-in channel", default: None, required: false, channel: true },
        OptInfo { name: "cs", help: "chip-select channel (omit: always selected)", default: None, required: false, channel: true },
        OptInfo { name: "mode", help: "SPI mode 0-3 (CPOL<<1 | CPHA)", default: Some("0"), required: false, channel: false },
        OptInfo { name: "cs_active", help: "low or high", default: Some("low"), required: false, channel: false },
        OptInfo { name: "bits", help: "word size 1-32", default: Some("8"), required: false, channel: false },
        OptInfo { name: "order", help: "msb or lsb first", default: Some("msb"), required: false, channel: false },
    ],
};

pub struct Spi {
    clk: u8,
    mosi: Option<u8>,
    miso: Option<u8>,
    cs: Option<u8>,
    cs_low: bool,
    rise: bool,
    bits: u8,
    lsb: bool,
    lines: Lines,
    active: bool,
    n: u8,
    vm: u32,
    vs: u32,
    start: u64,
    tstart: u64,
    words: Vec<(u32, u32)>,
}

impl Spi {
    pub fn new(spec: &Spec) -> Result<Self> {
        let clk = spec.ch("clk")?.ok_or_else(|| spec.usage("missing clk="))?;
        let (mosi, miso, cs) = (spec.ch("mosi")?, spec.ch("miso")?, spec.ch("cs")?);
        if mosi.is_none() && miso.is_none() {
            return Err(spec.usage("need mosi=CH and/or miso=CH"));
        }
        let mode: u8 = spec.num("mode", 0)?;
        if mode > 3 {
            return Err(spec.usage("mode must be 0-3"));
        }
        let bits: u8 = spec.num("bits", 8)?;
        if !(1..=32).contains(&bits) {
            return Err(spec.usage("bits must be 1-32"));
        }
        let cs_low = match spec.get("cs_active").unwrap_or("low") {
            "low" => true,
            "high" => false,
            o => return Err(spec.usage(format!("cs_active={o}: use low or high"))),
        };
        let lsb = match spec.get("order").unwrap_or("msb") {
            "msb" => false,
            "lsb" => true,
            o => return Err(spec.usage(format!("order={o}: use msb or lsb"))),
        };
        let (cpol, cpha) = (mode >> 1, mode & 1);
        Ok(Spi {
            clk,
            mosi,
            miso,
            cs,
            cs_low,
            rise: cpol == cpha,
            bits,
            lsb,
            lines: Lines::default(),
            active: cs.is_none(),
            n: 0,
            vm: 0,
            vs: 0,
            start: 0,
            tstart: 0,
            words: Vec::new(),
        })
    }

    fn hex(&self, v: u32) -> String {
        format!("{v:0w$x}", w = usize::from(self.bits).div_ceil(4))
    }

    fn word_event(&self) -> Event {
        let mut parts = Vec::new();
        let mut ev = Event::new(self.start, "spi", "word", "");
        if self.mosi.is_some() {
            parts.push(format!("MOSI 0x{}", self.hex(self.vm)));
            ev = ev.with("mosi", self.vm);
        }
        if self.miso.is_some() {
            parts.push(format!("MISO 0x{}", self.hex(self.vs)));
            ev = ev.with("miso", self.vs);
        }
        ev.text = parts.join(" ");
        ev
    }

    fn transfer_event(&self, out: &mut Vec<Event>) {
        if self.words.is_empty() {
            return;
        }
        let join = |sel: fn(&(u32, u32)) -> u32| {
            self.words.iter().map(|w| self.hex(sel(w))).collect::<Vec<_>>().join(" ")
        };
        let mut ev = Event::new(self.tstart, "spi", "transfer", "").with("words", self.words.len());
        let mut parts = vec!["transfer".to_string()];
        if self.mosi.is_some() {
            let m = join(|w| w.0);
            parts.push(format!("mosi=[{m}]"));
            ev = ev.with("mosi", m.replace(' ', ""));
        }
        if self.miso.is_some() {
            let s = join(|w| w.1);
            parts.push(format!("miso=[{s}]"));
            ev = ev.with("miso", s.replace(' ', ""));
        }
        ev.text = parts.join(" ");
        out.push(ev);
    }
}

impl Decoder for Spi {
    fn feed(&mut self, edges: &[Edge], out: &mut Vec<Event>) {
        let mut lines = std::mem::take(&mut self.lines);
        lines.steps(edges, |st| {
            if let Some(cs) = self.cs {
                if st.first(cs) || st.rose(cs) || st.fell(cs) {
                    let selected = st.high(cs) != self.cs_low;
                    if selected && !self.active {
                        self.active = true;
                        self.n = 0;
                        self.vm = 0;
                        self.vs = 0;
                        self.words.clear();
                        self.tstart = st.sample;
                    } else if !selected && self.active {
                        if self.n > 0 {
                            out.push(
                                Event::new(self.start, "spi", "error", format!("incomplete word ({} bits)", self.n))
                                    .with("error", "incomplete"),
                            );
                        }
                        self.transfer_event(out);
                        self.active = false;
                    }
                }
            }
            let edge = if self.rise { st.rose(self.clk) } else { st.fell(self.clk) };
            if !self.active || !edge {
                return;
            }
            if self.n == 0 {
                self.start = st.sample;
            }
            let bm = self.mosi.is_some_and(|c| st.high(c));
            let bs = self.miso.is_some_and(|c| st.high(c));
            if self.lsb {
                self.vm |= u32::from(bm) << self.n;
                self.vs |= u32::from(bs) << self.n;
            } else {
                self.vm = self.vm << 1 | u32::from(bm);
                self.vs = self.vs << 1 | u32::from(bs);
            }
            self.n += 1;
            if self.n == self.bits {
                out.push(self.word_event());
                self.words.push((self.vm, self.vs));
                self.n = 0;
                self.vm = 0;
                self.vs = 0;
            }
        });
        self.lines = lines;
    }

    fn finish(&mut self, _end: u64, _out: &mut Vec<Event>) {}
}
```

Decoding approach:
- Line state: FS J = (D+ 1, D− 0), K = (0, 1); LS swaps J and K; SE0 = (0, 0); SE1 = (1, 1).
- Each run of one state lasts `n = round(duration / bit)` bits. The transition into a run is a 0 bit, and the remaining `n − 1` bits are 1s (NRZI).
- Bit-unstuffing drops the 0 that follows six 1s. A 1 in that position is a `bitstuff` error.
- SE0 inside a packet is EOP. Runs shorter than half a bit are glitches from D+/D− skew: they are dropped and their time is added to the next run.

```rust
use crate::decode::usb::{crc5_11, crc16};

/// (D+, D-) for symbol 'J', 'K' or '0' (SE0).
pub fn usb_levels(sym: char, ls: bool) -> (bool, bool) {
    match (sym, ls) {
        ('0', _) => (false, false),
        ('J', false) | ('K', true) => (true, false),
        _ => (false, true),
    }
}

/// SYNC + bytes (PID first), LSB first, bit-stuffed, NRZI from idle J, then EOP (SE0 SE0 J).
pub fn usb_symbols(bytes: &[u8]) -> Vec<char> {
    let mut bits = vec![false, false, false, false, false, false, false, true];
    for b in bytes {
        for i in 0..8 {
            bits.push(b >> i & 1 == 1);
        }
    }
    let mut stuffed = Vec::new();
    let mut ones = 0;
    for b in bits {
        stuffed.push(b);
        if b {
            ones += 1;
            if ones == 6 {
                stuffed.push(false);
                ones = 0;
            }
        } else {
            ones = 0;
        }
    }
    let mut cur = 'J';
    let mut syms = Vec::new();
    for b in stuffed {
        if !b {
            cur = if cur == 'J' { 'K' } else { 'J' };
        }
        syms.push(cur);
    }
    syms.extend(['0', '0', 'J']);
    syms
}

pub fn usb_idle(w: &mut Wave, dp: u8, dm: u8, t: u64, ls: bool) {
    let (p, m) = usb_levels('J', ls);
    w.set(t, dp, p);
    w.set(t, dm, m);
}

/// Drive one packet from `t`; D- transitions lag D+ by `skew` samples. Returns end time.
#[allow(clippy::too_many_arguments)]
pub fn usb_packet(w: &mut Wave, dp: u8, dm: u8, t: f64, bit: f64, ls: bool, skew: u64, bytes: &[u8]) -> f64 {
    let syms = usb_symbols(bytes);
    for (i, &s) in syms.iter().enumerate() {
        let at = (t + i as f64 * bit).round() as u64;
        let (p, m) = usb_levels(s, ls);
        w.set(at, dp, p);
        w.set(at + skew, dm, m);
    }
    t + syms.len() as f64 * bit
}

pub fn usb_se0(w: &mut Wave, dp: u8, dm: u8, t: u64, dur: u64, ls: bool) {
    w.set(t, dp, false);
    w.set(t, dm, false);
    usb_idle(w, dp, dm, t + dur, ls);
}

fn usb_pid(pid: u8) -> u8 {
    pid | (!pid & 0x0f) << 4
}

fn usb_token11(pid: u8, v: u16) -> Vec<u8> {
    let f = v | u16::from(crc5_11(v)) << 11;
    vec![usb_pid(pid), f as u8, (f >> 8) as u8]
}

pub fn usb_token(pid: u8, addr: u8, ep: u8) -> Vec<u8> {
    usb_token11(pid, u16::from(addr) | u16::from(ep) << 7)
}

pub fn usb_sof(frame: u16) -> Vec<u8> {
    usb_token11(0x5, frame & 0x7ff)
}

pub fn usb_data(pid: u8, payload: &[u8]) -> Vec<u8> {
    let mut v = vec![usb_pid(pid)];
    v.extend_from_slice(payload);
    v.extend(crc16(payload).to_le_bytes());
    v
}

pub fn usb_handshake(pid: u8) -> Vec<u8> {
    vec![usb_pid(pid)]
}
```

```rust
pub fn crc5_bits(bits: impl IntoIterator<Item = bool>) -> u8 {
    let mut crc: u8 = 0x1f;
    for b in bits {
        let fb = (crc & 1) ^ u8::from(b);
        crc >>= 1;
        if fb != 0 {
            crc ^= 0x14;
        }
    }
    !crc & 0x1f
}

/// CRC5 over the 11-bit token field (address | endpoint << 7, or frame number).
pub fn crc5_11(v: u16) -> u8 {
    crc5_bits((0..11).map(|i| v >> i & 1 == 1))
}

pub fn crc16(data: &[u8]) -> u16 {
    let mut crc: u16 = 0xffff;
    for &b in data {
        crc ^= u16::from(b);
        for _ in 0..8 {
            crc = if crc & 1 != 0 { (crc >> 1) ^ 0xA001 } else { crc >> 1 };
        }
    }
    !crc
}

/// Name a standard SETUP request (8-byte setup packet). None for class/vendor requests.
pub fn describe_setup(d: &[u8]) -> Option<String> {
    if d.len() != 8 || d[0] & 0x60 != 0 {
        return None;
    }
    let value = u16::from_le_bytes([d[2], d[3]]);
    let len = u16::from_le_bytes([d[6], d[7]]);
    Some(match d[1] {
        0 => "GET_STATUS".into(),
        1 => "CLEAR_FEATURE".into(),
        3 => "SET_FEATURE".into(),
        5 => format!("SET_ADDRESS {value}"),
        6 => {
            let ty = match d[3] {
                1 => "Device",
                2 => "Configuration",
                3 => return Some(format!("GET_DESCRIPTOR String idx={} len={len}", d[2])),
                4 => "Interface",
                5 => "Endpoint",
                6 => "Device_Qualifier",
                7 => "Other_Speed_Configuration",
                15 => "BOS",
                0x21 => "HID",
                0x22 => "Report",

struct Raw {
    start: u64,
    bits: Vec<bool>,
    ones: u32,
    stuff_err: bool,
}

impl Raw {
    fn push(&mut self, b: bool) {
        if self.ones == 6 {
            self.ones = 0;
            if !b {
                return; // stuffed bit
            }
            self.stuff_err = true;
        }
        self.bits.push(b);
        self.ones = if b { self.ones + 1 } else { 0 };
    }

    /// A run of `n` bit times of one J/K state: transition (0) then n-1 ones.
    fn run(&mut self, n: u64) {
        self.push(false);
        for _ in 1..n {
            self.push(true);
        }
    }
}

pub struct Usb {
    dp: u8,
    dm: u8,
    rate: f64,
    ls: Option<bool>,
    bit: f64,
    lines: Lines,
    sym: Option<Sym>,
    since: u64,
    raw: Option<Raw>,
    suspended: bool,
    show_sof: bool,
    show_naks: bool,
    packets: bool,
    naks: u64,
    txn: Option<Txn>,
}

impl Usb {
    pub fn new(spec: &Spec, rate: f64) -> Result<Self> {
        let dp = spec.ch("dp")?.ok_or_else(|| spec.usage("missing dp="))?;
        let dm = spec.ch("dm")?.ok_or_else(|| spec.usage("missing dm="))?;
        if dp == dm {
            return Err(spec.usage("dp and dm must be different channels"));
        }
        let ls = match spec.get("speed").unwrap_or("auto") {
            "auto" => None,
            "fs" | "full" => Some(false),
            "ls" | "low" => Some(true),
            o => return Err(spec.usage(format!("speed={o}: use auto, fs or ls"))),
        };
        let min = if ls == Some(false) { 48e6 } else { 6e6 };
        if rate < min {
            return Err(spec.usage(format!(
                "sample rate {rate} Hz is too low (need at least {min} Hz; use 100M for full speed)"
            )));
        }
        let mut u = Usb {
            dp,
            dm,
            rate,
            ls: None,
            bit: 0.0,
            lines: Lines::default(),
            sym: None,
            since: 0,
            raw: None,
            suspended: false,
            show_sof: spec.flag("show_sof"),
            show_naks: spec.flag("naks"),
            packets: spec.flag("packets"),
            naks: 0,
            txn: None,
        };
        if let Some(l) = ls {
            u.set_speed(l);
        }
        Ok(u)
    }

    fn set_speed(&mut self, ls: bool) {
        self.ls = Some(ls);
        self.bit = self.rate / if ls { 1.5e6 } else { 12e6 };
    }

    fn sym(&self, dp: bool, dm: bool) -> Sym {
        let ls = self.ls == Some(true);
        match (dp, dm) {
            (false, false) => Sym::Se0,
            (true, true) => Sym::Se1,
            (true, false) => if ls { Sym::K } else { Sym::J },
            (false, true) => if ls { Sym::J } else { Sym::K },
        }
    }

    fn step(&mut self, sample: u64, dp: bool, dm: bool, out: &mut Vec<Event>) {
        if self.ls.is_none() {
            let ls = match (dp, dm) {
                (true, false) => false,
                (false, true) => true,
                _ => return,
            };
            self.set_speed(ls);
            let name = if ls { "low" } else { "full" };
            out.push(Event::new(sample, "usb", "info", format!("{name} speed (auto)")).with("speed", name));
            if !ls && self.rate < 48e6 {
                out.push(err(sample, "rate", "sample rate too low for full speed (need >= 48 MHz)"));
            }
        }
        let new = self.sym(dp, dm);
        match self.sym {
            Some(old) if old == new => {}
            Some(old) => {
                let dur = sample - self.since;
                if (dur as f64) < 0.5 * self.bit {
                    self.sym = Some(new); // glitch: its time goes to the next run
                    return;
                }
                self.run(old, self.since, dur, out);
                self.since = sample;
                self.sym = Some(new);
            }
            None => {
                self.since = sample;
                self.sym = Some(new);
            }
        }
    }

    fn run(&mut self, sym: Sym, start: u64, dur: u64, out: &mut Vec<Event>) {
        let n = ((dur as f64 / self.bit).round() as u64).max(1);
        let secs = dur as f64 / self.rate;
        let Some(raw) = self.raw.as_mut() else {
            match sym {
                Sym::J if secs >= 3e-3 && !self.suspended => {
                    self.suspended = true;
                    self.flush_txn(out);
                    out.push(Event::new(start + (3e-3 * self.rate) as u64, "usb", "suspend", "suspend"));
                }
                Sym::Se0 if secs >= 2.5e-6 => {
                    self.flush_txn(out);
                    self.suspended = false;
                    out.push(
                        Event::new(start, "usb", "reset", format!("bus reset {}", format_time(secs)))
                            .with("duration_s", secs),
                    );
                }
                Sym::K => {
                    if self.suspended {
                        self.suspended = false;
                        out.push(Event::new(start, "usb", "resume", "resume"));
                        if n > 8 {
                            return;
                        }
                    }
                    let mut raw = Raw { start, bits: Vec::new(), ones: 0, stuff_err: false };
                    raw.run(n);
                    self.raw = Some(raw);
                }
                _ => {}
            }
            return;
        };
        match sym {
            Sym::J | Sym::K => raw.run(n),
            Sym::Se0 => {
                let raw = self.raw.take().expect("in packet");
                self.packet(raw, out);
            }
            Sym::Se1 => {
                let raw = self.raw.take().expect("in packet");
                out.push(err(raw.start, "se1", "SE1 line state inside packet"));
            }
        }
    }

    fn packet(&mut self, raw: Raw, out: &mut Vec<Event>) {
        let start = raw.start;
        if raw.stuff_err {
            out.push(err(start, "bitstuff", "bit-stuffing violation"));
            return;
        }
        let bytes: Vec<u8> =
            raw.bits.chunks_exact(8).map(|c| c.iter().rev().fold(0u8, |a, &b| a << 1 | u8::from(b))).collect();
        if bytes.len() < 2 || bytes[0] != 0x80 {
            out.push(err(start, "sync", "bad SYNC"));
            return;
        }
        let p = bytes[1];
        if p & 0x0f != !(p >> 4) & 0x0f {
            out.push(err(start, "pid", format!("bad PID byte 0x{p:02x}")));
            return;
        }
        let pid = p & 0x0f;
        let body = &bytes[2..];
        let short = || err(start, "short", format!("{} packet too short", pid_name(pid)));
        let pkt = match pid {
            0x1 | 0x9 | 0xD | 0x4 | 0x5 => {
                if body.len() < 2 {
                    out.push(short());
                    return;
                }
                let v = u16::from_le_bytes([body[0], body[1]]);
                if crc5_11(v & 0x7ff) != (v >> 11) as u8 {
                    out.push(err(start, "crc5", format!("{} CRC5 mismatch", pid_name(pid))));
                    return;
                }
                if pid == 0x5 {
                    Packet::Sof { frame: v & 0x7ff }
                } else {
                    Packet::Token { pid, addr: (v & 0x7f) as u8, ep: (v >> 7 & 0xf) as u8 }
                }
            }
            0x3 | 0xB | 0x7 | 0xF => {
                if body.len() < 2 {
                    out.push(short());
                    return;
                }
                let (data, crc) = body.split_at(body.len() - 2);
                if crc16(data) != u16::from_le_bytes([crc[0], crc[1]]) {
                    out.push(err(start, "crc16", format!("{} CRC16 mismatch", pid_name(pid))).with("data", hex(data)));
                    return;
                }
                Packet::Data { pid, data: data.to_vec() }
            }
            0x2 | 0xA | 0xE | 0x6 => Packet::Handshake { pid },
            _ => Packet::Other { pid },
        };
        if self.packets {
            out.push(packet_event(start, &pkt));
        }
        self.transact(start, pkt, out);
    }

    fn transact(&mut self, start: u64, p: Packet, out: &mut Vec<Event>) {
        match p {
            Packet::Token { pid, addr, ep } => {
                self.flush_txn(out);
                self.txn = Some(Txn { start, token: Some((pid, addr, ep)), data: None });
            }
            Packet::Sof { frame } => {
                self.flush_txn(out);
                if self.show_sof {
                    out.push(Event::new(start, "usb", "sof", format!("SOF {frame}")).with("frame", frame));
                }
            }
            Packet::Data { pid, data } => {
                if let Some(t) = self.txn.as_mut().filter(|t| t.data.is_none()) {
                    t.data = Some((pid, data));
                } else {
                    self.flush_txn(out);
                    self.txn = Some(Txn { start, token: None, data: Some((pid, data)) });
                }
            }
            Packet::Handshake { pid } => {
                let t = self.txn.take().unwrap_or(Txn { start, token: None, data: None });
                self.emit_txn(t, Some(pid), out);
            }
            Packet::Other { pid } => {
                self.flush_txn(out);
                if !self.packets {
                    out.push(packet_event(start, &Packet::Other { pid }));
                }
            }
        }
    }

    fn flush_txn(&mut self, out: &mut Vec<Event>) {
        if let Some(t) = self.txn.take() {
            self.emit_txn(t, None, out);
        }
    }

    fn emit_txn(&mut self, t: Txn, hs: Option<u8>, out: &mut Vec<Event>) {
        if hs == Some(0xA) && !self.show_naks {
            self.naks += 1;
            return;
        }
        let mut parts = Vec::new();
        let mut ev = Event::new(t.start, "usb", "transaction", "");
        if let Some((pid, addr, ep)) = t.token {
            parts.push(format!("{} addr={addr} ep={ep}", pid_name(pid)));
            ev = ev.with("pid", pid_name(pid)).with("addr", addr).with("ep", ep);
        }
        if let Some((dpid, data)) = &t.data {
            parts.push(format!("{} [{}]", pid_name(*dpid), hex_spaced(data)));
            ev = ev.with("data_pid", pid_name(*dpid)).with("data", hex(data));
            if t.token.is_some_and(|tk| tk.0 == 0xD) {
                if let Some(r) = describe_setup(data) {
                    parts.push(r.clone());
                    ev = ev.with("request", r);
                }
            }
        }
        let hs_name = hs.map(pid_name);
        parts.push(hs_name.unwrap_or("no handshake").to_string());
        ev = ev.with("handshake", hs_name);
        ev.text = parts.join(" ");
        out.push(ev);
    }
}

fn packet_event(start: u64, p: &Packet) -> Event {
    match p {
        Packet::Token { pid, addr, ep } => {
            Event::new(start, "usb", "packet", format!("{} addr={addr} ep={ep}", pid_name(*pid)))
                .with("pid", pid_name(*pid))
                .with("addr", *addr)
                .with("ep", *ep)
        }
        Packet::Sof { frame } => {
            Event::new(start, "usb", "packet", format!("SOF {frame}")).with("pid", "SOF").with("frame", *frame)
        }
        Packet::Data { pid, data } => {
            Event::new(start, "usb", "packet", format!("{} [{}]", pid_name(*pid), hex_spaced(data)))
                .with("pid", pid_name(*pid))
                .with("data", hex(data))
        }
        Packet::Handshake { pid } | Packet::Other { pid } => {
            Event::new(start, "usb", "packet", pid_name(*pid)).with("pid", pid_name(*pid))
        }
    }
}

impl Decoder for Usb {
    fn feed(&mut self, edges: &[Edge], out: &mut Vec<Event>) {
        let mut lines = std::mem::take(&mut self.lines);
        let (dp, dm) = (self.dp, self.dm);
        lines.steps(edges, |st| {
            let known = |c| st.was_known(c) || st.touched(c);
            if (st.touched(dp) || st.touched(dm)) && known(dp) && known(dm) {
                self.step(st.sample, st.high(dp), st.high(dm), out);
            }
        });
        self.lines = lines;
    }

    fn finish(&mut self, end: u64, out: &mut Vec<Event>) {
        if self.raw.is_none() && self.sym == Some(Sym::J) {
            self.run(Sym::J, self.since, end.saturating_sub(self.since), out);
        }
        if let Some(raw) = self.raw.take() {
            out.push(err(raw.start, "truncated", "packet cut off at end of capture"));
        }
        self.flush_txn(out);
        if self.naks > 0 {
            out.push(
                Event::new(end, "usb", "info", format!("{} NAKed transactions not shown (add naks to show)", self.naks))
                    .with("naks", self.naks),
            );
        }
    }
}
```

```rust
//! Value Change Dump, one 1-bit wire per channel named D<n>.

use std::collections::HashMap;
use std::io::{Read, Write};

use crate::error::Result;
use crate::export::{Recording, Writer, invalid};
use crate::stream::Edge;

pub struct VcdWriter<W: Write> {
    out: W,
    ps: u64,
    last: Option<u64>,
}

fn id(ch: u8) -> char {
    (b'A' + ch) as char
}

impl<W: Write> VcdWriter<W> {
    pub fn new(mut out: W, mask: u16, rate: f64) -> Result<Self> {
        writeln!(out, "$version la1010 {} $end", env!("CARGO_PKG_VERSION"))?;
        writeln!(out, "$timescale 1 ps $end")?;
        writeln!(out, "$scope module la1010 $end")?;
        for ch in (0..16u8).filter(|c| mask >> c & 1 == 1) {
            writeln!(out, "$var wire 1 {} D{ch} $end", id(ch))?;
        }
        writeln!(out, "$upscope $end\n$enddefinitions $end")?;
        Ok(VcdWriter { out, ps: (1e12 / rate).round() as u64, last: None })
    }
}

impl<W: Write> Writer for VcdWriter<W> {
    fn edges(&mut self, edges: &[Edge]) -> Result<()> {
        for e in edges {
            if self.last != Some(e.sample) {
                writeln!(self.out, "#{}", e.sample * self.ps)?;
                self.last = Some(e.sample);
            }
            writeln!(self.out, "{}{}", u8::from(e.level), id(e.ch))?;
        }
        Ok(())
    }

    fn finish(mut self: Box<Self>, end: u64) -> Result<()> {
        if self.last != Some(end) {
            writeln!(self.out, "#{}", end * self.ps)?;
        }
        self.out.flush()?;
        Ok(())
    }
}

/// Timescale like "1ps" or "10 ns" -> time units per second.
fn units_per_second(s: &str) -> Result<f64> {
    let s = s.trim();
    let split = s.find(|c: char| !c.is_ascii_digit()).unwrap_or(s.len());
    let n: f64 = s[..split].parse().map_err(|_| invalid(format!("VCD: bad timescale '{s}'")))?;
    let unit = match s[split..].trim() {
        "s" => 1.0,
        "ms" => 1e3,
        "us" => 1e6,
        "ns" => 1e9,
        "ps" => 1e12,
        "fs" => 1e15,
        u => return Err(invalid(format!("VCD: bad timescale unit '{u}'"))),
    };
    Ok(unit / n)
}

fn gcd(a: u64, b: u64) -> u64 {
    if b == 0 { a } else { gcd(b, a % b) }
}

pub fn read(mut r: impl Read) -> Result<Recording> {
    let mut text = String::new();
    r.read_to_string(&mut text)?;
    let mut tok = text.split_whitespace();
    let mut ups: Option<f64> = None;
    let mut ids: HashMap<String, u8> = HashMap::new();
    let mut used = 0u16;
    let mut t: u64 = 0;
    let mut changes: Vec<(u64, u8, bool)> = Vec::new();
    while let Some(w) = tok.next() {
        match w {
            "$timescale" => {
                let s: String = tok.by_ref().take_while(|x| *x != "$end").collect();
                ups = Some(units_per_second(&s)?);
            }
            "$var" => {
                let v: Vec<&str> = tok.by_ref().take_while(|x| *x != "$end").collect();
                if v.len() >= 4 && v[1] == "1" {
                    let named = v[3]
                        .strip_prefix('D')
                        .and_then(|n| n.parse::<u8>().ok())
                        .filter(|c| *c < 16 && used >> c & 1 == 0);
                    if let Some(ch) = named.or_else(|| (0..16).find(|c| used >> c & 1 == 0)) {
                        used |= 1 << ch;
                        ids.insert(v[2].to_string(), ch);
                    }
                }
            }
            "$dumpvars" | "$dumpall" | "$dumpon" | "$dumpoff" | "$end" => {}
            w if w.starts_with('$') => {
                for x in tok.by_ref() {
                    if x == "$end" {
                        break;
                    }
                }
            }
            w if w.starts_with('#') => {
                t = w[1..].parse().map_err(|_| invalid(format!("VCD: bad timestamp '{w}'")))?;
            }
            w if w.starts_with(['b', 'B', 'r', 'R']) => {
                tok.next();
            }
            w => {
                let mut c = w.chars();
                let v = c.next();
                if let Some(&ch) = ids.get(c.as_str()) {
                    changes.push((t, ch, v == Some('1')));
                }
            }
        }
    }
    let ups = ups.ok_or_else(|| invalid("VCD: missing $timescale"))?;
    let end_t = changes.iter().map(|c| c.0).max().unwrap_or(0).max(t);
    let g = changes.iter().map(|c| c.0).chain([end_t]).fold(0, gcd).max(1);
    changes.sort_by_key(|c| (c.0, c.1));
    let mut last: [Option<bool>; 16] = [None; 16];
    let mut edges = Vec::new();
    for (t, ch, level) in changes {
        if last[ch as usize] != Some(level) {
            edges.push(Edge { sample: t / g, ch, level });
            last[ch as usize] = Some(level);
        }
    }
    Ok(Recording { rate: ups / g as f64, mask: used, edges, end: end_t / g })
}
```

```rust
//! sigrok session files (srzip v2), readable by PulseView and sigrok-cli.

use std::fs::File;
use std::io::{Read, Write};

use zip::write::SimpleFileOptions;
use zip::{CompressionMethod, ZipArchive, ZipWriter};

use crate::error::{Error, Result};
use crate::export::{Recording, Writer, invalid};
use crate::stream::Edge;
use crate::units::parse_si;

const CHUNK: usize = 4 << 20;

fn zerr(e: zip::result::ZipError) -> Error {
    Error::Io(std::io::Error::other(e))
}

fn opts() -> SimpleFileOptions {
    SimpleFileOptions::default().compression_method(CompressionMethod::Deflated)
}

pub struct SrWriter {
    zip: ZipWriter<File>,
    levels: u16,
    pos: u64,
    chunk: Vec<u8>,
    n: u32,
}

impl SrWriter {
    pub fn new(file: File, mask: u16, rate: f64) -> Result<Self> {
        let mut zip = ZipWriter::new(file);
        zip.start_file("version", opts()).map_err(zerr)?;
        zip.write_all(b"2")?;
        let mut meta = format!(
            "[global]\nsigrok version=0.5.2\n\n[device 1]\ncapturefile=logic-1\ntotal probes=16\nsamplerate={}\ntotal analog=0\n",
            rate.round() as u64
        );
        for ch in (0..16).filter(|c| mask >> c & 1 == 1) {
            meta.push_str(&format!("probe{}=D{ch}\n", ch + 1));
        }
        meta.push_str("unitsize=2\n");
        zip.start_file("metadata", opts()).map_err(zerr)?;
        zip.write_all(meta.as_bytes())?;
        Ok(SrWriter { zip, levels: 0, pos: 0, chunk: Vec::with_capacity(CHUNK), n: 0 })
    }

    fn fill(&mut self, until: u64) -> Result<()> {
        let bytes = self.levels.to_le_bytes();
        while self.pos < until {
            let room = (CHUNK - self.chunk.len()) / 2;
            let k = room.min((until - self.pos) as usize);
            for _ in 0..k {
                self.chunk.extend_from_slice(&bytes);
            }
            self.pos += k as u64;
            if self.chunk.len() == CHUNK {
                self.flush_chunk()?;
            }
        }
        Ok(())
    }

    fn flush_chunk(&mut self) -> Result<()> {
        if self.chunk.is_empty() {
            return Ok(());
        }
        self.n += 1;
        self.zip.start_file(format!("logic-1-{}", self.n), opts()).map_err(zerr)?;
        self.zip.write_all(&self.chunk)?;
        self.chunk.clear();
        Ok(())
    }
}

impl Writer for SrWriter {
    fn edges(&mut self, edges: &[Edge]) -> Result<()> {
        for e in edges {
            self.fill(e.sample)?;
            let bit = 1u16 << e.ch;
            self.levels = if e.level { self.levels | bit } else { self.levels & !bit };
        }
        Ok(())
    }

    fn finish(mut self: Box<Self>, end: u64) -> Result<()> {
        self.fill(end)?;
        self.flush_chunk()?;
        self.zip.finish().map_err(zerr)?;
        Ok(())
    }
}

/// "10000000", "10 MHz", "500 kHz".
pub fn parse_rate(v: &str) -> Result<f64> {
    let t = v.trim();
    let t = t.strip_suffix("Hz").unwrap_or(t).replace(' ', "");
    parse_si(&t).ok_or_else(|| invalid(format!("sr: bad samplerate '{v}'")))
}

pub fn read(file: File) -> Result<Recording> {
    let mut zip = ZipArchive::new(file).map_err(zerr)?;
    let mut meta = String::new();
    zip.by_name("metadata").map_err(zerr)?.read_to_string(&mut meta)?;
    let (mut rate, mut unitsize, mut mask) = (None, 1usize, 0u16);
    for line in meta.lines() {
        let Some((k, v)) = line.split_once('=') else { continue };
        match k.trim() {
            "samplerate" => rate = Some(parse_rate(v)?),
            "unitsize" => unitsize = v.trim().parse().map_err(|_| invalid("sr: bad unitsize"))?,
            k => {
                if let Some(n) = k.strip_prefix("probe").and_then(|n| n.parse::<u8>().ok()) {
                    if (1..=16).contains(&n) {
                        mask |= 1 << (n - 1);
                    }
                }
            }
        }
    }
    let rate = rate.ok_or_else(|| invalid("sr: no samplerate"))?;
    if !(1..=8).contains(&unitsize) {
        return Err(invalid("sr: bad unitsize"));
    }
    let mut chunks: Vec<u32> =
        zip.file_names().filter_map(|n| n.strip_prefix("logic-1-")?.parse().ok()).collect();
    chunks.sort_unstable();
    let (mut edges, mut levels, mut pos) = (Vec::new(), 0u16, 0u64);
    for n in chunks {
        let mut data = Vec::new();
        zip.by_name(&format!("logic-1-{n}")).map_err(zerr)?.read_to_end(&mut data)?;
        for s in data.chunks_exact(unitsize) {
            let v = (u16::from(s[0]) | if unitsize > 1 { u16::from(s[1]) << 8 } else { 0 }) & mask;
            let diff = if pos == 0 { mask } else { v ^ levels };
            for ch in (0..16u8).filter(|c| diff >> c & 1 == 1) {
                edges.push(Edge { sample: pos, ch, level: v >> ch & 1 == 1 });
            }
            levels = v;
            pos += 1;
        }
    }
    Ok(Recording { rate, mask, edges, end: pos })
}
```

```rust
//! CSV: one row per sample where any channel changes, plus a final row at the end.

use std::io::Write;

use crate::error::Result;
use crate::export::Writer;
use crate::stream::Edge;

pub struct CsvWriter<W: Write> {
    out: W,
    channels: Vec<u8>,
    rate: f64,
    levels: u16,
    pending: Option<u64>,
}

impl<W: Write> CsvWriter<W> {
    pub fn new(mut out: W, mask: u16, rate: f64) -> Result<Self> {
        let channels: Vec<u8> = (0..16).filter(|c| mask >> c & 1 == 1).collect();
        let head: String = channels.iter().map(|c| format!(",D{c}")).collect();
        writeln!(out, "time_s{head}")?;
        Ok(CsvWriter { out, channels, rate, levels: 0, pending: None })
    }

    fn row(&mut self, sample: u64) -> Result<()> {
        let vals: String = self.channels.iter().map(|c| format!(",{}", self.levels >> c & 1)).collect();
        writeln!(self.out, "{:.9}{vals}", sample as f64 / self.rate)?;
        Ok(())
    }
}

impl<W: Write> Writer for CsvWriter<W> {
    fn edges(&mut self, edges: &[Edge]) -> Result<()> {
        for e in edges {
            if let Some(p) = self.pending.filter(|p| *p != e.sample) {
                self.row(p)?;
            }
            self.pending = Some(e.sample);
            let bit = 1u16 << e.ch;
            self.levels = if e.level { self.levels | bit } else { self.levels & !bit };
        }
        Ok(())
    }

    fn finish(mut self: Box<Self>, end: u64) -> Result<()> {
        if let Some(p) = self.pending {
            self.row(p)?;
            if p != end {
                self.row(end)?;
            }
        }
        self.out.flush()?;
        Ok(())
    }
}
```

```rust
//! Intel HEX -> flat binary (FX2 images are stored as HEX in KingstVIS).

use crate::error::{Error, Result};

const MAX_IMAGE: usize = 16 << 20;

fn bad(m: impl Into<String>) -> Error {
    Error::Firmware(format!("Intel HEX: {}", m.into()))
}

pub fn decode(text: &[u8]) -> Result<Vec<u8>> {
    let text = std::str::from_utf8(text).map_err(|_| bad("not text"))?;
    let mut img: Vec<u8> = Vec::new();
    let mut base: usize = 0;
    for line in text.lines().map(str::trim).filter(|l| !l.is_empty()) {
        let hex = line.strip_prefix(':').ok_or_else(|| bad(format!("bad line '{line}'")))?;
        let rec: Vec<u8> = (0..hex.len())
            .step_by(2)
            .map(|i| hex.get(i..i + 2).and_then(|b| u8::from_str_radix(b, 16).ok()))
            .collect::<Option<_>>()
            .ok_or_else(|| bad(format!("bad hex in '{line}'")))?;
        if rec.len() < 5 || rec.len() != rec[0] as usize + 5 {
            return Err(bad(format!("bad length in '{line}'")));
        }
        if rec.iter().fold(0u8, |a, b| a.wrapping_add(*b)) != 0 {
            return Err(bad(format!("checksum mismatch in '{line}'")));
        }
        let data = &rec[4..rec.len() - 1];
        match rec[3] {
            0 => {
                let addr = base + usize::from(u16::from_be_bytes([rec[1], rec[2]]));
                let end = addr + data.len();
                if end > MAX_IMAGE {
                    return Err(bad("image larger than 16 MiB"));
                }
                if img.len() < end {
                    img.resize(end, 0);
                }
                img[addr..end].copy_from_slice(data);
            }
            1 => break,
            4 if data.len() == 2 => base = usize::from(u16::from_be_bytes([data[0], data[1]])) << 16,
            4 => return Err(bad("bad extended address record")),
            _ => {}
        }
    }
    Ok(img)
}

pub fn maybe_decode(data: Vec<u8>) -> Result<Vec<u8>> {
    if data.first() == Some(&b':') { decode(&data) } else { Ok(data) }
}
```

```rust
/// Build (data, names, tree) for root -> dirs -> zlib-compressed files.
pub fn rcc(dirs: &[(&str, Vec<(&str, Vec<u8>)>)]) -> (Vec<u8>, Vec<u8>, Vec<u8>) {
    let (mut data, mut names, mut tree) = (Vec::new(), Vec::new(), Vec::new());
    let dir_entry = |tree: &mut Vec<u8>, n: u32, count: usize, first: usize| {
        tree.extend(n.to_be_bytes());
        tree.extend(2u16.to_be_bytes());
        tree.extend((count as u32).to_be_bytes());
        tree.extend((first as u32).to_be_bytes());
    };
    let root = name(&mut names, "");
    dir_entry(&mut tree, root, dirs.len(), 1);
    let mut next = 1 + dirs.len();
    for (d, files) in dirs {
        let n = name(&mut names, d);
        dir_entry(&mut tree, n, files.len(), next);
        next += files.len();
    }
    for (_, files) in dirs {
        for (f, content) in files {
            let mut z = ZlibEncoder::new(Vec::new(), Compression::default());
            z.write_all(content).unwrap();
            let mut blob = (content.len() as u32).to_be_bytes().to_vec();
            blob.extend(z.finish().unwrap());
            let off = data.len() as u32;
            data.extend((blob.len() as u32).to_be_bytes());
            data.extend(blob);
            let n = name(&mut names, f);
            tree.extend(n.to_be_bytes());
            tree.extend(1u16.to_be_bytes());
            tree.extend(0u16.to_be_bytes());
            tree.extend(0u16.to_be_bytes());
            tree.extend(off.to_be_bytes());
        }
    }
```

```rust
//! Qt rcc resource tree (format version 1) -> (path, bytes).

use std::io::Read;

use flate2::read::ZlibDecoder;

use crate::error::{Error, Result};

const COMPRESSED: u16 = 0x01;
const DIR: u16 = 0x02;
const ENTRY: usize = 14;
const MAX_DEPTH: u32 = 16;

fn bad(m: &str) -> Error {
    Error::Firmware(format!("Qt resources: {m}"))
}

fn be16(b: &[u8], o: usize) -> Result<u16> {
    b.get(o..o + 2).map(|s| u16::from_be_bytes([s[0], s[1]])).ok_or_else(|| bad("truncated"))
}

fn be32(b: &[u8], o: usize) -> Result<u32> {
    b.get(o..o + 4).map(|s| u32::from_be_bytes([s[0], s[1], s[2], s[3]])).ok_or_else(|| bad("truncated"))
}

fn name_at(names: &[u8], o: usize) -> Result<String> {
    let len = usize::from(be16(names, o)?);
    let raw = names.get(o + 6..o + 6 + 2 * len).ok_or_else(|| bad("truncated name"))?;
    let units: Vec<u16> = raw.chunks_exact(2).map(|c| u16::from_be_bytes([c[0], c[1]])).collect();
    String::from_utf16(&units).map_err(|_| bad("bad name"))
}

fn blob_at(data: &[u8], o: usize) -> Result<&[u8]> {
    let len = be32(data, o)? as usize;
    data.get(o + 4..o + 4 + len).ok_or_else(|| bad("truncated data"))
}

pub fn files(data: &[u8], names: &[u8], tree: &[u8]) -> Result<Vec<(String, Vec<u8>)>> {
    if be16(tree, 4)? & DIR == 0 {
        return Err(bad("root is not a directory"));
    }
    let mut out = Vec::new();
    walk(data, names, tree, 0, "", 0, &mut out)?;
    Ok(out)
}

fn walk(
    data: &[u8],
    names: &[u8],
    tree: &[u8],
    node: usize,
    prefix: &str,
    depth: u32,
    out: &mut Vec<(String, Vec<u8>)>,
) -> Result<()> {
    if depth > MAX_DEPTH {
        return Err(bad("tree too deep"));
    }
    let off = node * ENTRY;
    let count = be32(tree, off + 6)? as usize;
    let first = be32(tree, off + 10)? as usize;
    for child in first..first.saturating_add(count) {
        let c = child * ENTRY;
        let name = name_at(names, be32(tree, c)? as usize)?;
        let flags = be16(tree, c + 4)?;
        let path = if prefix.is_empty() { name } else { format!("{prefix}/{name}") };
        if flags & DIR != 0 {
            walk(data, names, tree, child, &path, depth + 1, out)?;
            continue;
        }
        let raw = blob_at(data, be32(tree, c + 10)? as usize)?;
        let bytes = if flags & COMPRESSED != 0 {
            let mut v = Vec::new();
            ZlibDecoder::new(raw.get(4..).ok_or_else(|| bad("truncated data"))?)
                .read_to_end(&mut v)
                .map_err(|_| bad("bad zlib data"))?;
            v
        } else {
            raw.to_vec()
        };
        out.push((path, bytes));
    }
    Ok(())
}
```

```rust
fn fw_err(m: impl Into<String>) -> Error {

fn symbol<'a>(file: &object::File<'a>, name: &str) -> Result<&'a [u8]> {
    let sym = file
        .symbols()
        .find(|s| s.name().is_ok_and(|n| n == name))
        .ok_or_else(|| fw_err(format!("symbol {name} not found: not a KingstVIS binary?")))?;
    let idx = sym.section_index().ok_or_else(|| fw_err(format!("{name}: no section")))?;
    let sec = file.section_by_index(idx).map_err(|e| fw_err(format!("{name}: {e}")))?;
    let data = sec.data().map_err(|e| fw_err(format!("{name}: {e}")))?;
    let off = (sym.address() - sec.address()) as usize;
    data.get(off..off + sym.size() as usize).ok_or_else(|| fw_err(format!("{name}: out of bounds")))
}

pub fn extract_from_elf(elf: &[u8]) -> Result<Vec<Blob>> {
    let file = object::File::parse(elf).map_err(|e| fw_err(format!("not an ELF binary: {e}")))?;
    let data = symbol(&file, "_ZL16qt_resource_data")?;
    let names = symbol(&file, "_ZL16qt_resource_name")?;
    let tree = symbol(&file, "_ZL18qt_resource_struct")?;
    let mut blobs = Vec::new();
    for (path, bytes) in qrc::files(data, names, tree)? {
        let name = match path.as_str() {
            "fwusb/fw01A2" => FX2.to_string(),
            p => match p.strip_prefix("fwfpga/LA1010") {
                Some(rev @ ("A0" | "A1" | "A2")) => bitstream_name(&rev.to_ascii_lowercase()),
                _ => continue,
            },
        };
        blobs.push(Blob { name, data: ihex::maybe_decode(bytes)? });
    }
    if !blobs.iter().any(|b| b.name == FX2) || blobs.len() < 2 {
        return Err(fw_err("KingstVIS binary does not contain the LA1010 firmware files"));
    }
    Ok(blobs)
}

pub fn from_targz(r: impl Read) -> Result<Vec<Blob>> {
    let mut ar = tar::Archive::new(flate2::read::GzDecoder::new(r));
    for entry in ar.entries()? {
        let mut e = entry?;
        let is_bin = e.path()?.file_name() == Some(OsStr::new("KingstVIS")) && e.header().entry_type().is_file();
        if is_bin {
            let mut v = Vec::new();
            e.read_to_end(&mut v)?;
            return extract_from_elf(&v);
        }
    }
    Err(fw_err("no KingstVIS/KingstVIS binary in archive"))
}

/// A KingstVIS Linux tarball, an unpacked directory, or the KingstVIS ELF binary.
pub fn extract_from_path(p: &Path) -> Result<Vec<Blob>> {
    let file = if p.is_dir() {
        [p.join("KingstVIS/KingstVIS"), p.join("KingstVIS")]
            .into_iter()
            .find(|c| c.is_file())
            .ok_or_else(|| fw_err(format!("{}: no KingstVIS binary in directory", p.display())))?
    } else {
        p.to_path_buf()
    };
    let data = fs::read(&file)?;
    match data.get(..4) {
        Some([0x1f, 0x8b, ..]) => from_targz(&data[..]),
        Some(b"\x7fELF") => extract_from_elf(&data),
        _ => Err(fw_err(format!("{}: not a KingstVIS tarball or Linux binary", file.display()))),
    }
}

pub fn crc32(d: &[u8]) -> u32 {
    let mut c = flate2::Crc::new();
    c.update(d);
    c.sum()
}

#[derive(Debug)]
pub struct Installed {
    pub name: String,
    pub path: PathBuf,
    pub size: usize,
    pub crc: u32,
    /// Some(true): matches v3.6.6; Some(false): differs; None: not in the table.
    pub known: Option<bool>,
}

pub fn install(blobs: &[Blob], dir: &Path) -> Result<Vec<Installed>> {
    fs::create_dir_all(dir)?;
    blobs
        .iter()
        .map(|b| {
            let path = dir.join(&b.name);
            let tmp = dir.join(format!(".{}.tmp", b.name));
            fs::write(&tmp, &b.data)?;
            fs::rename(&tmp, &path)?;
            let crc = crc32(&b.data);
            let known = KNOWN.iter().find(|k| k.0 == b.name).map(|k| k.1 == b.data.len() && k.2 == crc);
            Ok(Installed { name: b.name.clone(), path, size: b.data.len(), crc, known })
        })
        .collect()
}
```

```rust
//! LA1010 control protocol (vendor requests on EP0, bitstream on EP2).
//! USB-agnostic: everything goes through `Transport`. See the spec's "Device protocol".

use std::thread::sleep;
use std::time::Duration;

use crate::error::{Error, Result};
use crate::firmware::bitstream_name;

pub const VID: u16 = 0x77a1;
pub const PID: u16 = 0x01a2;

pub const REQ_FX2_RAM: u8 = 0xA0;
pub const REQ_EEPROM: u8 = 0xA2;
pub const REQ_FPGA_INIT: u8 = 0x50;
pub const REQ_FPGA_ENABLE: u8 = 0x10;
pub const REQ_FPGA_REG: u8 = 0x20;
pub const REQ_BULK_RESET: u8 = 0x38;
pub const REQ_BULK_START: u8 = 0x30;

const FX2_CPUCS: u16 = 0xE600;
const FX2_RAM: usize = 0x4000;
const REG_RUN: u16 = 0x00;
const REG_CAPT_MODE: u16 = 0x03;
const REG_PINS: u16 = 0x04;
const REG_SAMPLING: u16 = 0x10;
const REG_CHANNELS: u16 = 0x20;
const REG_THRESHOLD: u16 = 0x68;
const CHUNK: usize = 4096;
/// Hardware sample limit; streaming is stopped by the host long before.
const SAMPLE_LIMIT: u64 = 10_000_000_000;

pub trait Transport {
    fn ctrl_in(&self, request: u8, value: u16, index: u16, len: u16) -> Result<Vec<u8>>;
    fn ctrl_out(&self, request: u8, value: u16, index: u16, data: &[u8]) -> Result<()>;
    fn bulk_out(&mut self, data: &[u8]) -> Result<()>;
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Identity {
    pub magic: u8,
    pub magic2: u8,
    pub revision: &'static str,
    pub bitstream: String,
    pub manufactured: Option<String>,
}

pub fn revision(magic: u8) -> Option<&'static str> {
    match magic {
        0x04 => Some("a0"),
        0x07 => Some("a1"),
        0x0a => Some("a2"),
        _ => None,
    }
}

/// Model magic at EEPROM 0x08 (value, complement; primary and backup copy),
/// manufacturing date (BCD year, month, complements) at 0x20.
pub fn identify(t: &impl Transport) -> Result<Identity> {
    let b = t.ctrl_in(REQ_EEPROM, 0x08, 0, 8)?;
    let ok = |i: usize| b[i] ^ b[i + 1] == 0xff;
    let (magic, magic2) = if ok(0) && ok(2) {
        (b[0], b[2])
    } else if ok(4) && ok(6) {
        (b[4], b[6])
    } else if ok(0) {
        (b[0], 0)
    } else if ok(4) {
        (b[4], 0)
    } else {
        return Err(Error::Device(format!("EEPROM model bytes unreadable: {b:02x?}")));
    };
    let revision = revision(magic).ok_or_else(|| {
        Error::Device(format!("EEPROM magic 0x{magic:02x} is not an LA1010 (other Kingst models are not supported)"))
    })?;
    let d = t.ctrl_in(REQ_EEPROM, 0x20, 0, 4)?;
    let manufactured =
        (d[0] ^ d[2] == 0xff && d[1] ^ d[3] == 0xff).then(|| format!("20{:02x}-{:02x}", d[0], d[1]));
    Ok(Identity { magic, magic2, revision, bitstream: bitstream_name(revision), manufactured })
}

/// Load FX2 RAM via the EZ-USB loader (hold CPU in reset, write, release).
pub fn fx2_upload(t: &impl Transport, fw: &[u8]) -> Result<()> {
    if fw.len() > FX2_RAM {
        return Err(Error::Firmware(format!("FX2 image is {} bytes, larger than 16 KiB RAM", fw.len())));
    }
    t.ctrl_out(REQ_FX2_RAM, FX2_CPUCS, 0, &[1])?;
    for (i, chunk) in fw.chunks(CHUNK).enumerate() {
        t.ctrl_out(REQ_FX2_RAM, (i * CHUNK) as u16, 0, chunk)?;
    }
    t.ctrl_out(REQ_FX2_RAM, FX2_CPUCS, 0, &[0])
}

/// FPGA init status 0 means a bitstream is loaded.
pub fn fpga_ready(t: &impl Transport) -> Result<bool> {
    Ok(t.ctrl_in(REQ_FPGA_INIT, 0, 0, 1)?[0] == 0)
}

pub fn fpga_upload(t: &mut impl Transport, bits: &[u8]) -> Result<()> {
    t.ctrl_out(REQ_FPGA_INIT, 0, 0, &(bits.len() as u32).to_le_bytes())?;
    let mut padded = bits.to_vec();
    padded.resize(bits.len().div_ceil(CHUNK) * CHUNK, 0);
    for chunk in padded.chunks(CHUNK) {
        t.bulk_out(chunk)?;
    }
    let st = t.ctrl_in(REQ_FPGA_INIT, 0, 0, 1)?[0];
    if st != 0 {
        return Err(Error::Device(format!("FPGA rejected the bitstream (status 0x{st:02x})")));
    }
    sleep(Duration::from_millis(30));
    t.ctrl_out(REQ_FPGA_ENABLE, 1, 0, &[])?;
    sleep(Duration::from_millis(40));
    Ok(())
}

/// Two PWM duty values (R56, R79) driving the threshold bias DAC.
pub fn threshold_regs(v: f64) -> Result<[u8; 4]> {
    if !(-4.0..=4.0).contains(&v) {
        return Err(Error::Usage(format!("threshold {v} V is outside -4.0..4.0 V")));
    }
    let (r79, r56): (u16, f64) = if v >= 2.9 {
        (0, 302.0 * v - 363.0)
    } else if v > -0.4 {
        (0x00f2, 302.0 * v + 121.0)
    } else {
        (0x02d7, 302.0 * v + 1090.0)
    };
    let r56 = (r56 as i64).clamp(10, 1100) as u16;
    let mut b = [0u8; 4];
    b[..2].copy_from_slice(&r56.to_le_bytes());
    b[2..].copy_from_slice(&r79.to_le_bytes());
    Ok(b)
}

/// u40 sample limit, u40 pre-trigger samples (0), u24 pre-trigger memory >> 8 (1),
/// u16 divider of the 800 MHz base clock, u8 0.
pub fn sample_config(divider: u16) -> [u8; 16] {
    let mut b = [0u8; 16];
    b[..5].copy_from_slice(&SAMPLE_LIMIT.to_le_bytes()[..5]);
    b[10] = 1;
    b[13..15].copy_from_slice(&divider.to_le_bytes());
    b
}

/// u32 enabled-channel mask, then three u32 trigger words (unused: no HW trigger when streaming).
pub fn channel_config(mask: u16) -> [u8; 16] {
    let mut b = [0u8; 16];
    b[..4].copy_from_slice(&u32::from(mask).to_le_bytes());
    b
}

pub fn configure(t: &impl Transport, mask: u16, divider: u16, volts: f64) -> Result<()> {
    t.ctrl_out(REQ_FPGA_REG, REG_THRESHOLD, 0, &threshold_regs(volts)?)?;
    t.ctrl_out(REQ_FPGA_REG, REG_CAPT_MODE, 0, &[1])?;
    t.ctrl_out(REQ_FPGA_REG, REG_CHANNELS, 16, &channel_config(mask))?;
    t.ctrl_out(REQ_FPGA_REG, REG_SAMPLING, 0, &sample_config(divider))
}

pub fn flush(t: &impl Transport) -> Result<()> {
    t.ctrl_out(REQ_BULK_RESET, 0, 0, &[])
}

/// Run, then start bulk data. Bulk IN transfers must already be queued.
pub fn start(t: &impl Transport) -> Result<()> {
    t.ctrl_out(REQ_FPGA_REG, REG_RUN, 0, &[3])?;
    t.ctrl_out(REQ_BULK_START, 0, 0, &[])
}

pub fn halt(t: &impl Transport) -> Result<()> {
    t.ctrl_out(REQ_FPGA_REG, REG_RUN, 0, &[0])
}

pub fn pins(t: &impl Transport) -> Result<u16> {
    let b = t.ctrl_in(REQ_FPGA_REG, REG_PINS, 0, 2)?;
    Ok(u16::from_le_bytes([b[0], b[1]]))
}
```

```rust
//! nusb-backed transport and device bring-up (FX2 RAM firmware, FPGA bitstream).

use std::path::Path;
use std::thread::sleep;
use std::time::{Duration, Instant};

use nusb::MaybeFuture;
use nusb::transfer::{Buffer, Bulk, ControlIn, ControlOut, ControlType, Out, Recipient};

use crate::device::{self, Identity, PID, REQ_EEPROM, Transport, VID};
use crate::error::{Error, Result};
use crate::firmware;

const TIMEOUT: Duration = Duration::from_millis(500);

pub struct Usb {
    dev: nusb::Device,
    pub(crate) intf: Option<nusb::Interface>,
    ep_out: Option<nusb::Endpoint<Bulk, Out>>,
}

fn usb_err(what: &str, e: impl std::fmt::Display) -> Error {
    Error::Device(format!("{what}: {e}"))
}

impl Transport for Usb {
    fn ctrl_in(&self, request: u8, value: u16, index: u16, len: u16) -> Result<Vec<u8>> {
        let d = self
            .dev
            .control_in(
                ControlIn { control_type: ControlType::Vendor, recipient: Recipient::Device, request, value, index, length: len },
                TIMEOUT,
            )
            .wait()
            .map_err(|e| usb_err(&format!("control in 0x{request:02x}"), e))?;
        if d.len() != usize::from(len) {
            return Err(Error::Device(format!("control in 0x{request:02x}: got {} of {len} bytes", d.len())));
        }
        Ok(d)
    }

    fn ctrl_out(&self, request: u8, value: u16, index: u16, data: &[u8]) -> Result<()> {
        self.dev
            .control_out(
                ControlOut { control_type: ControlType::Vendor, recipient: Recipient::Device, request, value, index, data },
                TIMEOUT,
            )
            .wait()
            .map_err(|e| usb_err(&format!("control out 0x{request:02x}"), e))
    }

    fn bulk_out(&mut self, data: &[u8]) -> Result<()> {
        if self.ep_out.is_none() {
            let intf = self.intf.as_ref().ok_or_else(|| Error::Device("interface not claimed".into()))?;
            self.ep_out = Some(intf.endpoint::<Bulk, Out>(0x02).map_err(|e| usb_err("open EP2", e))?);
        }
        let ep = self.ep_out.as_mut().expect("just opened");
        let c = ep.transfer_blocking(Buffer::from(data.to_vec()), Duration::from_secs(1));
        c.status.map_err(|e| usb_err("bulk out EP2", e))?;
        if c.actual_len != data.len() {
            return Err(Error::Device(format!("bulk out EP2: wrote {} of {} bytes", c.actual_len, data.len())));
        }
        Ok(())
    }
}

fn open_raw() -> Result<Usb> {
    let info = nusb::list_devices()
        .wait()
        .map_err(|e| usb_err("list USB devices", e))?
        .find(|d| d.vendor_id() == VID && d.product_id() == PID)
        .ok_or_else(|| Error::Device("no Kingst LA1010 found (USB 77a1:01a2)".into()))?;
    let dev = info.open().wait().map_err(|e| usb_err("open device", e))?;
    Ok(Usb { dev, intf: None, ep_out: None })
}

/// The EZ-USB loader stalls vendor requests other than 0xA0; our firmware answers EEPROM reads.
fn fx2_running(u: &Usb) -> bool {
    u.ctrl_in(REQ_EEPROM, 0x20, 0, 4).is_ok()
}

fn wait_reenumeration() -> Result<Usb> {
    sleep(Duration::from_millis(1800));
    let deadline = Instant::now() + Duration::from_secs(3);
    loop {
        if let Ok(u) = open_raw() {
            if fx2_running(&u) {
                return Ok(u);
            }
        }
        if Instant::now() > deadline {
            return Err(Error::Device("device did not re-enumerate within 3 s after FX2 firmware upload".into()));
        }
        sleep(Duration::from_millis(200));
    }
}

pub struct Opened {
    pub usb: Usb,
    pub id: Identity,
    pub fx2_loaded: bool,
    pub fpga_loaded: bool,
}

/// Find the analyzer, load FX2 firmware and FPGA bitstream if needed, leave it halted.
pub fn open(fw_dir: Option<&Path>) -> Result<Opened> {
    let mut usb = open_raw()?;
    let mut fx2_loaded = false;
    if !fx2_running(&usb) {
        let fw = firmware::load(firmware::FX2, fw_dir)?;
        usb.dev.set_configuration(1).wait().map_err(|e| usb_err("set configuration", e))?;
        device::fx2_upload(&usb, &fw)?;
        drop(usb);
        usb = wait_reenumeration()?;
        fx2_loaded = true;
    }
    usb.intf = Some(usb.dev.claim_interface(0).wait().map_err(|e| usb_err("claim interface 0", e))?);
    let id = device::identify(&usb)?;
    let mut fpga_loaded = false;
    if !device::fpga_ready(&usb)? {
        let bits = firmware::load(&id.bitstream, fw_dir)?;
        device::fpga_upload(&mut usb, &bits)?;
        fpga_loaded = true;
    }
    device::halt(&usb)?;
    Ok(Opened { usb, id, fx2_loaded, fpga_loaded })
}
```

```rust
//! Streaming acquisition: queued bulk IN transfers on EP6, halt guaranteed on exit.

use std::sync::atomic::{AtomicBool, Ordering};
use std::time::{Duration, Instant};

use nusb::transfer::{Bulk, In};

use crate::device;
use crate::error::{Error, Result};
use crate::usb::Usb;

const XFERS: usize = 8;

pub struct Setup {
    pub mask: u16,
    pub divider: u16,
    pub rate: f64,
    pub threshold: f64,
}

pub struct Stats {
    pub bytes: u64,
    pub elapsed: Duration,
}

/// About 50 ms of data per transfer, in whole 512-byte packets, max 512 KiB.
pub fn transfer_size(bytes_per_sec: f64) -> usize {
    ((bytes_per_sec * 0.05) as usize / 512 * 512).clamp(512, 512 * 1024)
}

struct Halt<'a>(&'a Usb);

impl Drop for Halt<'_> {
    fn drop(&mut self) {
        let _ = device::halt(self.0);
    }
}

pub fn stream(usb: &Usb, s: &Setup, stop: &AtomicBool, mut sink: impl FnMut(&[u8]) -> Result<bool>) -> Result<Stats> {
    let bps = s.rate * f64::from(s.mask.count_ones()) / 8.0;
    let size = transfer_size(bps);
    device::configure(usb, s.mask, s.divider, s.threshold)?;
    device::flush(usb)?;
    let intf = usb.intf.as_ref().ok_or_else(|| Error::Device("interface not claimed".into()))?;
    let mut ep = intf.endpoint::<Bulk, In>(0x86).map_err(|e| Error::Device(format!("open EP6: {e}")))?;
    for _ in 0..XFERS {
        let b = ep.allocate(size);
        ep.submit(b);
    }
    let halt = Halt(usb);
    device::start(usb)?;
    let t0 = Instant::now();
    let mut last = t0;
    let mut total = 0u64;
    let slack = (XFERS * size) as f64 + 8.0 * 1024.0 * 1024.0;
    let stall = Duration::from_secs(2) + Duration::from_secs_f64(2.0 * size as f64 / bps);
    let result = loop {
        if stop.load(Ordering::Relaxed) {
            break Ok(());
        }
        let Some(c) = ep.wait_next_complete(Duration::from_millis(100)) else {
            if last.elapsed() > stall {
                break Err(Error::Device(format!("stream stalled: no data for {:.1} s", last.elapsed().as_secs_f64())));
            }
            continue;
        };
        if let Err(e) = c.status {
            break Err(Error::Device(format!("bulk read EP6: {e}")));
        }
        last = Instant::now();
        total += c.actual_len as u64;
        match sink(&c.buffer[..c.actual_len]) {
            Ok(true) => {}
            Ok(false) => break Ok(()),
            Err(e) => break Err(e),
        }
        let el = t0.elapsed().as_secs_f64();
        if el > 0.5 && bps * el - total as f64 > slack {
            break Err(Error::Device(format!(
                "overrun: received {total} of ~{:.0} bytes after {el:.2} s; lower the rate or channel count",
                bps * el
            )));
        }
        ep.submit(c.buffer);
    };
    drop(halt);
    ep.cancel_all();
    while ep.pending() > 0 && ep.wait_next_complete(Duration::from_secs(1)).is_some() {}
    result.map(|()| Stats { bytes: total, elapsed: t0.elapsed() })
}
```

```rust
//! Window -> decoders / measure / file writer -> printer, with --until / --count.

use std::io::Write;

use crate::decode::Decoder;
use crate::error::Result;
use crate::export::Writer;
use crate::measure::Measure;
use crate::output::{Event, Printer};
use crate::stream::Edge;
use crate::window::Window;

pub struct Outcome {
    pub triggered: bool,
    pub hit: bool,
    pub decoded: u64,
}

pub struct Pipeline<W: Write> {
    window: Window,
    decoders: Vec<Box<dyn Decoder>>,
    measure: Option<Measure>,
    writer: Option<Box<dyn Writer>>,
    printer: Printer<W>,
    until: Option<String>,
    count: Option<u64>,
    decoded: u64,
    hit: bool,
    edges: Vec<Edge>,
    events: Vec<Event>,
}

impl<W: Write> Pipeline<W> {
    pub fn new(window: Window, decoders: Vec<Box<dyn Decoder>>, printer: Printer<W>) -> Self {
        Pipeline {
            window,
            decoders,
            measure: None,
            writer: None,
            printer,
            until: None,
            count: None,
            decoded: 0,
            hit: false,
            edges: Vec::new(),
            events: Vec::new(),
        }
    }

    pub fn measure(mut self, m: Measure) -> Self {
        self.measure = Some(m);
        self
    }

    pub fn writer(mut self, w: Box<dyn Writer>) -> Self {
        self.writer = Some(w);
        self
    }

    pub fn stop_on(mut self, until: Option<String>, count: Option<u64>) -> Self {
        self.until = until;
        self.count = count;
        self
    }

    pub fn triggered(&self) -> bool {
        self.window.triggered()
    }

    /// Feed absolute edges; `now` = samples processed so far. Returns false to stop.
    pub fn push(&mut self, edges: &[Edge], now: u64) -> Result<bool> {
        self.edges.clear();
        let done = self.window.push(edges, now, &mut self.edges);
        if let Some(t) = self.window.trigger_sample() {
            self.printer.set_origin(t);
        }
        if !self.edges.is_empty() {
            for d in &mut self.decoders {
                d.feed(&self.edges, &mut self.events);
            }
            if let Some(m) = &mut self.measure {
                m.feed(&self.edges);
            }
            if let Some(w) = &mut self.writer {
                w.edges(&self.edges)?;
            }
        }
        self.emit()?;
        Ok(!done && !self.hit)
    }

    fn emit(&mut self) -> Result<()> {
        self.events.sort_by_key(|e| e.sample);
        for e in self.events.drain(..) {
            if self.hit {
                break;
            }
            let line = self.printer.print(&e)?;
            if !matches!(e.kind, "info" | "error") {
                self.decoded += 1;
            }
            let until = self.until.as_deref().is_some_and(|u| line.contains(u));
            if until || self.count.is_some_and(|c| self.decoded >= c) {
                self.hit = true;
            }
        }
        self.printer.flush()
    }

    pub fn finish(mut self, now: u64) -> Result<Outcome> {
        let end = self.window.output_len(now);
        if self.window.triggered() && !self.hit {
            for d in &mut self.decoders {
                d.finish(end, &mut self.events);
            }
        }
        if let Some(m) = &self.measure {
            self.events.extend(Measure::events(&m.finish()));
        }
        self.emit()?;
        if let Some(w) = self.writer.take() {
            w.finish(end)?;
        }
        Ok(Outcome { triggered: self.window.triggered(), hit: self.hit, decoded: self.decoded })
    }
}
```

```rust
//! Subcommand implementations.

use std::io::{self, Write};
use std::path::Path;
use std::sync::atomic::{AtomicBool, Ordering};

use la1010::capture::{self, Setup};
use la1010::decode::{self, Decoder, Spec};
use la1010::error::{Error, Result};
use la1010::measure::Measure;
use la1010::output::Printer;
use la1010::pipeline::{Outcome, Pipeline};
use la1010::stream::Deinterleaver;
use la1010::window::{Trigger, Window};
use la1010::{device, export, firmware, units, usb};
use serde_json::json;

use crate::{Acq, CaptureArgs, Cli, Cmd, DecodeArgs, FwCmd, MeasureArgs, MonitorArgs};

static STOP: AtomicBool = AtomicBool::new(false);

pub fn run(cli: Cli) -> Result<i32> {
    let fw = cli.firmware_dir.as_deref();
    let json = cli.json;
    match cli.cmd {
        Cmd::Info => info(fw, json),
        Cmd::Firmware { cmd: FwCmd::Fetch { out, url } } => install(&firmware::fetch(&url)?, out.as_deref(), fw, json),
        Cmd::Firmware { cmd: FwCmd::Extract { path, out } } => {
            install(&firmware::extract_from_path(&path)?, out.as_deref(), fw, json)
        }
        Cmd::Measure(a) => measure(fw, json, &a),
        Cmd::Capture(a) => capture_cmd(fw, json, &a),
        Cmd::Monitor(a) => monitor(fw, json, &a),
        Cmd::Decode(a) => decode_file(json, &a),
        Cmd::Decoders { name } => decoders(name.as_deref(), json),
    }
}

struct Plan {
    mask: u16,
    rate: f64,
    divider: u16,
    specs: Vec<Spec>,
    trigger: Option<Trigger>,
}

fn parse_specs(decode: &[String]) -> Result<Vec<Spec>> {
    decode.iter().map(|s| Spec::parse(s)).collect()
}

fn plan(acq: &Acq, decode: &[String], trigger: Option<&str>) -> Result<Plan> {
    let specs = parse_specs(decode)?;
    let trigger = trigger.map(Trigger::parse).transpose()?;
    let mut need = 0u16;
    for s in &specs {
        need |= s.channel_mask()?;
    }
    if let Some(t) = &trigger {
        need |= t.mask();
    }
    let mask = match &acq.channels {
        Some(c) => {
            let m = units::parse_channels(c)?;
            if need & !m != 0 {
                return Err(Error::Usage(format!(
                    "-c {c} does not include the decoder/trigger channels (mask 0x{need:04x})"
                )));
            }
            m
        }
        None if need != 0 => need,
        None => 0xffff,
    };
    let want = match &acq.rate {
        Some(r) => units::parse_rate(r)?,
        None if specs.is_empty() => 10e6,
        None => specs.iter().map(decode::recommended_rate).collect::<Result<Vec<_>>>()?.into_iter().fold(0.0, f64::max),
    };
    let (rate, divider) = units::snap_rate(want)?;
    if (rate - want).abs() / want > 1e-3 {
        eprintln!("la1010: rate {} -> {} (800 MHz / {divider})", units::fmt_hz(want), units::fmt_hz(rate));
    }
    let bps = rate * f64::from(mask.count_ones());
    if bps > units::VERIFIED_BPS {
        eprintln!(
            "la1010: warning: {:.0} Mbit/s exceeds the verified lossless {:.0} Mbit/s; an overrun aborts the capture",
            bps / 1e6,
            units::VERIFIED_BPS / 1e6
        );
    }
    Ok(Plan { mask, rate, divider, specs, trigger })
}

fn decoders_for(specs: &[Spec], rate: f64) -> Result<Vec<Box<dyn Decoder>>> {
    specs.iter().map(|s| decode::build(s, rate)).collect()
}

fn samples(d: &str, rate: f64) -> Result<u64> {
    Ok((units::parse_duration(d)?.as_secs_f64() * rate).round() as u64)
}

fn stdout_printer(json: bool, rate: f64) -> Printer<io::StdoutLock<'static>> {
    Printer::new(io::stdout().lock(), json, rate)
}

fn acquire<W: Write>(
    fw: Option<&Path>,
    p: &Plan,
    threshold: f64,
    mut pipe: Pipeline<W>,
    max_wait: u64,
) -> Result<Outcome> {
    let _ = ctrlc::set_handler(|| STOP.store(true, Ordering::Relaxed));
    let opened = usb::open(fw)?;
    let mut deint = Deinterleaver::new(p.mask);
    let mut edges = Vec::new();
    let setup = Setup { mask: p.mask, divider: p.divider, rate: p.rate, threshold };
    let res = capture::stream(&opened.usb, &setup, &STOP, |bytes| {
        edges.clear();
        deint.push(bytes, &mut edges);
        let more = pipe.push(&edges, deint.samples())?;
        Ok(more && (pipe.triggered() || deint.samples() < max_wait))
    });
    let outcome = pipe.finish(deint.samples());
    res?;
    outcome
}

fn check_stop(o: &Outcome, until: Option<&str>, count: Option<u64>) -> Result<i32> {
    if o.hit || (until.is_none() && count.is_none()) {
        return Ok(0);
    }
    Err(Error::NoResult(match until {
        Some(u) => format!("'{u}' not seen"),
        None => format!("only {} of {} events", o.decoded, count.unwrap_or(0)),
    }))
}

fn info(fw: Option<&Path>, json: bool) -> Result<i32> {
    let o = usb::open(fw)?;
    let pins = device::pins(&o.usb)?;
    let dirs: Vec<String> = firmware::dirs(fw).iter().map(|d| d.display().to_string()).collect();
    let mut out = io::stdout().lock();
    if json {
        let v = json!({
            "model": "LA1010", "revision": o.id.revision, "magic": o.id.magic, "magic2": o.id.magic2,
            "manufactured": o.id.manufactured, "bitstream": o.id.bitstream,
            "fx2_uploaded": o.fx2_loaded, "fpga_uploaded": o.fpga_loaded, "pins": pins, "firmware_dirs": dirs,
        });
        writeln!(out, "{v}")?;
    } else {
        let state = |b: bool| if b { "uploaded now" } else { "already running" };
        writeln!(out, "model         LA1010 rev {} (EEPROM magic 0x{:02x}/0x{:02x})", o.id.revision, o.id.magic, o.id.magic2)?;
        writeln!(out, "manufactured  {}", o.id.manufactured.as_deref().unwrap_or("unknown"))?;
        writeln!(out, "fx2 firmware  {}", state(o.fx2_loaded))?;
        writeln!(out, "fpga          {} ({})", o.id.bitstream, state(o.fpga_loaded))?;
        writeln!(out, "pins          0x{pins:04x}")?;
    }
    Ok(0)
}

fn install(blobs: &[firmware::Blob], out: Option<&Path>, fw: Option<&Path>, json: bool) -> Result<i32> {
    let dir = match out {
        Some(d) => d.to_path_buf(),
        None => firmware::install_dir(fw)?,
    };
    let mut stdout = io::stdout().lock();
    for r in firmware::install(blobs, &dir)? {
        let status = match r.known {
            Some(true) => "verified",
            Some(false) => "differs from KingstVIS v3.6.6",
            None => "not in table",
        };
        if r.known == Some(false) {
            eprintln!(
                "la1010: warning: {} (size {}, crc32 {:08x}) differs from the tested KingstVIS v3.6.6 file; installed anyway",
                r.name, r.size, r.crc
            );
        }
        if json {
            let v = json!({"file": r.name, "path": r.path.display().to_string(), "size": r.size,
                           "crc32": format!("{:08x}", r.crc), "status": status});
            writeln!(stdout, "{v}")?;
        } else {
            writeln!(stdout, "{}  {} B  crc32 {:08x}  {status}", r.path.display(), r.size, r.crc)?;
        }
    }
    Ok(0)
}

fn measure(fw: Option<&Path>, json: bool, a: &MeasureArgs) -> Result<i32> {
    let p = plan(&a.acq, &[], None)?;
    let total = samples(&a.duration, p.rate)?.max(1);
    let pipe = Pipeline::new(Window::new(p.mask, None, 0, total), Vec::new(), stdout_printer(json, p.rate))
        .measure(Measure::new(p.mask, p.rate));
    acquire(fw, &p, a.acq.threshold, pipe, u64::MAX)?;
    Ok(0)
}

fn capture_cmd(fw: Option<&Path>, json: bool, a: &CaptureArgs) -> Result<i32> {
    let p = plan(&a.acq, &a.decode, a.trigger.as_deref())?;
    let total = match a.samples {
        Some(n) => n,
        None => samples(a.duration.as_deref().unwrap_or("1s"), p.rate)?,
    };
    if total == 0 {
        return Err(Error::Usage("capture length is zero".into()));
    }
    if a.pre > 99 {
        return Err(Error::Usage("--pre must be 0-99".into()));
    }
    let pre = total * u64::from(a.pre) / 100;
    let window = Window::new(p.mask, p.trigger.clone(), pre, total);
    let mut pipe = Pipeline::new(window, decoders_for(&p.specs, p.rate)?, stdout_printer(json, p.rate));
    if let Some(o) = &a.output {
        pipe = pipe.writer(export::create(o, p.mask, p.rate)?);
    }
    let max_wait = if p.trigger.is_some() { samples(&a.timeout, p.rate)? } else { u64::MAX };
    let o = acquire(fw, &p, a.acq.threshold, pipe, max_wait)?;
    if p.trigger.is_some() && !o.triggered {
        return Err(Error::NoResult(format!("trigger not reached within {}", a.timeout)));
    }
    Ok(0)
}

fn monitor(fw: Option<&Path>, json: bool, a: &MonitorArgs) -> Result<i32> {
    let p = plan(&a.acq, &a.decode, None)?;
    let len = match samples(&a.timeout, p.rate)? {
        0 => u64::MAX,
        n => n,
    };
    let pipe = Pipeline::new(Window::new(p.mask, None, 0, len), decoders_for(&p.specs, p.rate)?, stdout_printer(json, p.rate))
        .stop_on(a.until.clone(), a.count);
    let o = acquire(fw, &p, a.acq.threshold, pipe, u64::MAX)?;
    check_stop(&o, a.until.as_deref(), a.count)
}

fn decode_file(json: bool, a: &DecodeArgs) -> Result<i32> {
    let specs = parse_specs(&a.decode)?;
    let rec = export::read(&a.file)?;
    for s in &specs {
        if s.channel_mask()? & !rec.mask != 0 {
            return Err(s.usage(format!(
                "uses channels not present in {} (channels mask 0x{:04x})",
                a.file.display(),
                rec.mask
            )));
        }
    }
    let mut pipe = Pipeline::new(Window::new(rec.mask, None, 0, u64::MAX), decoders_for(&specs, rec.rate)?, stdout_printer(json, rec.rate))
        .stop_on(a.until.clone(), a.count);
    pipe.push(&rec.edges, rec.end)?;
    let o = pipe.finish(rec.end)?;
    check_stop(&o, a.until.as_deref(), a.count)
}

fn decoders(name: Option<&str>, json: bool) -> Result<i32> {
    let list = match name {
        Some(n) => vec![decode::info(n)?],
        None => decode::catalog(),
    };
    let mut out = io::stdout().lock();
    if json {
        let v: Vec<_> = list
            .iter()
            .map(|i| {
                let opts: Vec<_> = i
                    .opts
                    .iter()
                    .map(|o| json!({"name": o.name, "help": o.help, "default": o.default, "required": o.required, "channel": o.channel}))
                    .collect();
                json!({"name": i.name, "help": i.help, "options": opts})
            })
            .collect();
        writeln!(out, "{}", serde_json::Value::Array(v))?;
        return Ok(0);
    }
    for i in list {
        writeln!(out, "{}  {}", i.name, i.help)?;
        for o in i.opts {
            let mut tags = Vec::new();
            if o.required {
                tags.push("required".to_string());
            }
            if let Some(d) = o.default {
                tags.push(format!("default {d}"));
            }
            let tags = if tags.is_empty() { String::new() } else { format!(" ({})", tags.join(", ")) };
            writeln!(out, "    {:<10} {}{tags}", o.name, o.help)?;
        }
    }
    writeln!(out, "\nspec syntax: NAME:opt=val,opt=val,flag   e.g. uart:rx=0,baud=115200")?;
    Ok(0)
}
```

```markdown
# Kingst LA1010 logic analyzer (`la1010` CLI)

16 channels, streaming only, max 100 MSa/s; lossless limit: see "Limits". Inputs only — this
tool never drives outputs.

## First use
- `la1010 firmware fetch` once (downloads KingstVIS from qdkingst.com, installs 4 files).
- `la1010 info --json` → model, revision, firmware state. Exit 2 = not connected/firmware missing.

## Always
- Use `--json` and parse NDJSON: keys `t` (s, 0 = trigger), `sample`, `proto`, `kind`, fields, `text`.
- Every run is bounded: capture/measure default 1 s; monitor default `--timeout 10s`.
- Exit: 0 ok, 1 usage (fix args), 2 device/firmware/IO, 3 trigger/`--until`/`--count` not reached.
- Threshold `-t` default 1.4 V (fine for 1.8–5 V logic); use `-t 0.9` for 1.8 V-only buses.

## Recipes
- What is alive? `la1010 measure -c 0-15 --json` → per channel freq/duty/min_pulse or static level.
- Unknown UART: `la1010 capture -c 0 -d 2s --decode uart:rx=0 --json` (baud auto; first event
  `kind=info` reports it). Then pin it: `uart:rx=0,baud=115200`.
- I2C sniff from first START: `la1010 capture --decode i2c:scl=1,sda=0 --trigger 0:fall -d 500ms --json`.
- SPI with CS: `la1010 capture --decode spi:clk=0,mosi=1,miso=2,cs=3,mode=0 -d 200ms --json`.
- USB enumeration: `la1010 monitor --decode usb:dp=2,dm=3 --until GET_DESCRIPTOR --timeout 20s --json`
  then plug the device in. NAKs are counted, not printed (`naks` to show; `packets` for raw).
- Save for PulseView: add `-o capture.sr`; re-decode later: `la1010 decode capture.sr --decode …`.
- `la1010 decoders --json` lists every option.

## Limits
- (fill from docs/hardware-validation.md: lossless rate × channels table)
- USB full speed needs ≥ 48 MHz (default 100M, 2 channels). No USB high speed.
```
